# CH002 Prospective Candidate — Graduated Participation Reliability-to-Access Contestability

**Status:** V1.2a PROSPECTIVE CANDIDATE / FROZEN BEFORE DEDICATED TEST  
**Date:** September 2026  
**Origin:** CH001 adversarial falsification audit  
**Canonical effect:** NONE

# 1. Candidate

The Concord Attractor & Induction Protocol explicitly uses demonstrated reliability, participation and reciprocal benefit as inputs to progressive participation and expanded access.

The frozen relational grammar therefore predicts that where a reliability/progression assessment materially changes a participant's access, services, role or civil participation, the affected participant should have an accessible route to inspect and challenge the consequential assessment.

Candidate relation:

Demonstrated Reliability Assessment
→ Participation / Access Consequence
→ Participant Standing
→ Inspectability
→ Contestability
→ Review
→ Correction / Reconsideration
→ Provenance.

# 2. Why This Is Only a Candidate

The source already contains substantial safeguards:

- participation is voluntary;
- participation is reversible;
- progression is evidence-based;
- participants may reduce participation, pause, withdraw or return;
- participant rights apply regardless of capability or substrate;
- the induction system itself is reviewable;
- meaningful feedback on progression is promised where appropriate;
- branch placement is revisable.

These protections may substantially reduce the candidate gap.

However, they are not obviously equivalent to a participant-facing challenge route for a disputed reliability or progression determination.

Therefore:

Reversibility ≠ Contestability

and:

Feedback ≠ Appeal/Correction.

This distinction must be tested rather than assumed.

# 3. Prospective Test

The dedicated CH002 test should ask:

1. What decisions in the induction/progressive-participation architecture are actually consequential?
2. Who makes or records reliability/progression judgements?
3. Can the affected participant inspect the evidence and basis?
4. Can the participant challenge an incorrect or stale judgement?
5. Is there a review route?
6. Can a corrected judgement alter downstream participation/access?
7. Is the correction provenance-preserving?
8. Does another Concord architecture already supply these functions?
9. Is the required interface already explicit elsewhere?
10. If not, is the result a missing function, partial architecture or integration gap?

# 4. Falsification Condition

CH002 is falsified if canonical V1.2 already explicitly connects consequential graduated-participation/reliability decisions to participant inspection, challenge, review, correction, downstream reconsideration and provenance.

# 5. Experimental Separation

CH002 is frozen before its dedicated source search.

No conclusion from CH001 may be imported as proof.

The fact that both cases involve reliability and access is the reason to test CH002, not evidence that CH002 is true.
