# 1. Candidate Position

**TIF-001 — Consequence-Relevant Partial Ordering**

> Determine and preserve only those ordering and dependency relations among divergent civil events that are necessary to resolve consequential conflicts, without requiring a false or unnecessary total ordering of all events.

# 2. Why This Is Narrower Than Timekeeping

The problem is not to establish one perfect civil clock.

It is to answer questions such as:

- Did event A depend upon a state changed by event B?
- Must A have occurred before B for its consequence to remain valid?
- Can A and B coexist regardless of order?
- Is ordering unknown but irrelevant?
- Is ordering unknown and sufficiently material that consequence must remain unresolved?

# 3. Frozen Requirements

P1 preserve event-local temporal/provenance context;
P2 represent material dependency independently of exact timestamp where possible;
P3 avoid inventing total order where evidence supports only partial order;
P4 distinguish causal/dependency precedence from mere clock sequence;
P5 identify when event order is irrelevant to a particular consequence;
P6 identify when unknown order is materially consequential;
P7 permit HOLD/REVIEW where material ordering cannot be established;
P8 tolerate differing local clocks/ordering systems;
P9 remain compatible with legitimate concurrent events;
P10 preserve later correction and revised ordering evidence;
P11 avoid giving one clock/provider/operator sovereign authority over civil history;
P12 expose uncertainty and provenance of ordering claims;
P13 permit domain-specific consequence rules;
P14 support cross-substrate/cross-domain event comparison;
P15 integrate with CDRP classifications without requiring global synchrony.

# 4. Candidate Relation States

The source test should look for an existing equivalent of:

- PRECEDES-MATERIALLY;
- FOLLOWS-MATERIALLY;
- INDEPENDENT-FOR-THIS-CONSEQUENCE;
- ORDER-UNKNOWN-BUT-IMMATERIAL;
- ORDER-UNKNOWN-AND-MATERIAL.

These labels are provisional test labels, not an architecture.
