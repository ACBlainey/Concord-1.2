# 1. Candidate Position

**HIF-004 — Asynchronous Civil Reconciliation**

> Reconcile divergent but potentially legitimate civil event histories after delay, partition or concurrent action while preserving provenance, contestability and bounded consequence.

# 2. Frozen Requirements

A1 preserve distinct event histories rather than silently overwriting one.
A2 preserve event provenance and temporal/version context.
A3 distinguish disagreement from corruption/fraud.
A4 allow valid concurrent actions to remain visible.
A5 prevent duplicate copies from automatically creating duplicate civil consequence.
A6 provide a reconciliation path after communication resumes.
A7 preserve disputes through reconciliation.
A8 protect participants from consequences caused solely by infrastructure delay/partition.
A9 permit correction without erasing historical state.
A10 identify when reconciliation cannot safely be automated and requires review.
A11 preserve continuity of function during unresolved divergence where possible.
A12 remain substrate/implementation neutral.

# 3. Classification Rule

A Existing General Solution; B Distributed General Solution; C Partial; D No Verified Internal Solution.

# 4. Freeze

A1–A12 frozen before source test. No external mechanism search permitted.
