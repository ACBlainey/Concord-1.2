# 1. Candidate Higher-Order Position

**HIF-001 — Non-Sovereign Shared Civil Reference**

> Create shared civil reference functions that remain authoritative enough to coordinate civilisation while no ordinary node, provider, resolver, witness set or accessibility service becomes structurally sovereign.

# 2. Trigger Pattern

Shared Civil Function
+ Multiple Participants/Systems Depend Upon It
+ Consequential Coordination Requirement
+ Concentration Would Create Capture/Failure Risk
→ Require Non-Sovereign Coordination Architecture.

# 3. Frozen Required Properties

H1 shared reference can be relied upon sufficiently for its bounded civil function;
H2 no ordinary operator can unilaterally own/redefine the underlying participant right/status/function;
H3 operator failure does not destroy the shared civil function;
H4 operator replacement is possible;
H5 multiple operators/paths do not create uncontrolled contradictory civil realities;
H6 consequential changes are provenance-visible;
H7 affected participants have appropriate contestability;
H8 privacy exposure is proportional to function;
H9 authority remains function-bounded;
H10 emergency concentration, if ever permitted, is temporary/reviewable/terminable;
H11 the architecture can evolve implementation without redefining the underlying civil function;
H12 the coordination mechanism is itself subject to the same anti-capture grammar.
