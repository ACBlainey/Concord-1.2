# V1.2a — U-Kernel Counterfactual Concord Experiment

## Status

**EXPERIMENTAL / NON-CANONICAL / ISOLATED FROM V1.2**

V1.2a is a standalone experimental workspace within the Concord-1.2 repository.

It does **not** replace, amend, supersede or silently modify the existing V1.2 Concord.

The existing V1.2 architecture remains the reference Concord generated through the original E1 / Blainey's Laws ethical lineage.

V1.2a asks a different counterfactual question:

> **If a civilisational architecture were generated from the independently derived Unified Paths U1–U8 minimum-stable ethical kernel, would substantially the same Concord emerge?**

The purpose is not to force convergence or divergence. It is to determine what the alternative ethical starting geometry actually generates.

## Experimental Boundary

Work performed inside this folder must remain separate from canonical V1.2 material unless a later, explicit research decision is made to compare, test or integrate a result.

Existing V1.2 solutions should not be copied into the derivation space except where required as explicitly identified comparison evidence after a counterfactual result has been frozen.

V1.2a may ultimately show:

- strong convergence with V1.2;
- equivalent functions implemented through different architectures;
- localised differences;
- systematic alternative architecture;
- underdetermination;
- or insufficient generative constraint.

All are valid experimental outcomes.
