## Purpose

This folder is the development and eventual operating home for the **Civil Attention civilisational domain**.

Its initial domain function is civilisation-wide intake, preservation, routing visibility, resolution-state tracking and participant feedback for problems, suggestions and petitions.

> **Central Visibility ≠ Central Control.**

## Classification Basis

This folder records a domain identification, not a declaration that the existing source architecture is complete or validated.

The domain qualifies provisionally because it represents a persistent civilisational problem-space with distinct responsibilities, state or processes, boundaries, authority relationships, and interfaces with other Concord systems.

Existing repository systems and documents may implement, constrain, inform or interface with this domain without themselves defining the domain boundary.
