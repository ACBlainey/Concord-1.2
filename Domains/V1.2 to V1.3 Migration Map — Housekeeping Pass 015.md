## 2. Placeholder principle

The V1.2 placeholder paths preserve two different things:

1. Git/repository structure that would otherwise disappear because directories are empty;
2. evidence that a future work area was intentionally contemplated.

Those are not equivalent.

> **Placeholder Presence != Developed Architecture**

> **Planned Folder != Civilisational Capability**

> **Empty Work Area != System Gap Resolution**

A placeholder can be useful evidence of intent without establishing that the represented function was ever developed.

## 3. Migration treatment

**A1 — ARCHIVE IN PREDECESSOR**

There is no need to reproduce V1.2's obsolete placeholder topology inside V1.3.

The intact predecessor preserves the reconstruction record.
