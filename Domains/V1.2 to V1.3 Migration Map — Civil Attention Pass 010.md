# V1.2 to V1.3 Migration Map — Civil Attention Pass 010

**Status:** MIGRATION PLANNING / SELECTIVE MIGRATION / NO FILE MOVEMENT AUTHORISED

## 1. Core finding

Unlike several V1.2 roots, `12_Civil_Attention` is already substantially expressed as **current integrated Concord architecture**.

Its root status is:

**CONCORD SYSTEM INTEGRATION / CORRIGIBLE**

and its source method is a:

**GRADUATED PORTABLE MODULE / SUPPORTED / CORRIGIBLE**

Therefore Civil Attention is a strong example of material that should substantially migrate into V1.3 as living architecture.

> **Tell the Concord once; the Concord determines who needs to deal with it.**

Civil Attention is a genuine top-level domain because it performs the persistent civil function of making legitimate participant concerns visible, traceable, routable and reviewable without requiring participants to understand the civilisation's internal topology.

## 2. Domain boundary

Civil Attention centralises:
- intake;
- original-submission preservation;
- provisional classification;
- issue matching/creation;
- routing visibility;
- responsibility-resolution visibility;
- bounded status;
- central resolution state;
- participant feedback;
- challenge/reopening pathways.

It does **not** centralise substantive authority.

> **Central Visibility != Central Control**

> **Attention != Truth**

> **Attention != Priority**

> **Routing != Adjudication**

> **Routing != Authority to Resolve the Underlying Domain Question**

Civil Attention routes responsibility to legitimate functional owners and preserves the return path.

## 3. Core architecture to migrate

The current architecture should migrate substantially intact:

**Participant**
→ Common Civil Attention Intake
→ Receipt / Original Submission Preservation
→ Provisional Classification
→ Issue Matching / Issue Object
→ Multi-Domain Resolution
→ Domain Action Object(s)
→ Domain-Specific Examination / Action
→ Domain Status / Disposition Return
→ Central Resolution Record
→ Participant Feedback / Reviewability

This is current civil architecture, not merely development provenance.

## 14. Migration significance

Civil Attention provides a useful contrast with Intercivilisational Relations.

Intercivilisational Relations currently has a valid domain but substantial undeveloped architecture, so relatively little of its development corpus needs to migrate.

Civil Attention already has:
- an integrated system;
- participant-facing interfaces;
- standard forms;
- object/state architecture;
- a central resolution schema;
- domain binding rules;
- a cross-domain interface model;
- and a graduated portable core.

Therefore much more of its current operational layer should cross the V1.3 boundary.

This confirms that selective migration is based on **current function and state**, not a fixed percentage of each V1.2 folder.

> **Migration Weight Follows Live Architectural Need, Not Source Folder Size.**
