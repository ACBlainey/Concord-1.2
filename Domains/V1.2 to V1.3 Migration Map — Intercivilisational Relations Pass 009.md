# V1.2 to V1.3 Migration Map — Intercivilisational Relations Pass 009

**Status:** MIGRATION PLANNING / SELECTIVE MIGRATION / NO FILE MOVEMENT AUTHORISED

## 1. Core finding

Intercivilisational Relations remains a genuine top-level civil domain, but the existing V1.2 folder is primarily a **development workspace for that domain**, not a completed operational domain.

Its README describes development work on interoperability with civilisations that do not use full Concord architecture internally. Several child areas explicitly identify themselves as:

**UNDEVELOPED / NOT CANONICAL**

and the existing-civilisation variants are explicitly:

**COMPARATIVE RESEARCH AREA / NOT CANONICAL**

Therefore V1.3 should not simply copy 11_Intercivilisational_Architecture into the Intercivilisational Relations domain.

> **A Valid Domain Can Exist Before Its Operational Architecture Is Complete.**

The V1.3 domain should honestly expose that development gap.

## 2. Established domain boundary worth migrating

The current corpus establishes several strong architectural boundaries that are suitable for a live V1.3 domain specification:

> **Interoperability Without Forced Internal Uniformity**

> **Common Protocol != Common Government**

> **Wrapper Adoption != Concord Oversight**

> **Design Authorship != Operational Authority**

> **Technical Compatibility != Political Subordination**

> **Diplomatic Relationship != Transfer of Sovereignty**

> **Neutrality, Competence or Authorship of a Wrapper Does Not Manufacture Authority to Mediate**

These are current boundary findings rather than reasons to migrate every document that produced them.

## 3. Domain function

The persistent civil function is broader than wrapper design.

Intercivilisational Relations concerns legitimate relationships between the Concord and other civilisations/polities, and where appropriate relationships among external civilisations using compatible interfaces.

Likely persistent responsibilities include:
- diplomacy;
- recognition;
- interoperation;
- communication;
- negotiated relations;
- rights/standing translation across civil boundaries;
- peaceful distance;
- cross-boundary jurisdiction interfaces;
- cross-boundary externalities;
- treaty/agreement interfaces;
- trade/economic interfaces with Economy;
- external security interfaces with Defence;
- legal interfaces with Law/Judiciary;
- optional mediation only where separately authorised.

Wrapper architecture is a mechanism used by this domain, not the whole domain.

> **Intercivilisational Relations != Civilisational Wrapper Architecture**

## 15. Finding

The V1.2 folder proves that Intercivilisational Relations is a persistent civil function, but it also proves that much of its operational architecture remains unfinished.

V1.3 should therefore preserve the **domain** while shedding most of the **development corpus**.

This is a direct demonstration of the selective migration rule:

> **Migrate the Living Result; Archive the Developmental Path.**
