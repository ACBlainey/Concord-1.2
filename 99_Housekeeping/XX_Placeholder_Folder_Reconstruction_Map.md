## Purpose

This document records the folder and subfolder structure represented in Concord V1.2 by one-byte files named `xx`, together with other intentionally retained empty-work-area markers that should remain recoverable for future development.

These placeholder objects contain no substantive Concord material. Their function is to preserve or signal planned work areas that may otherwise disappear from, or be ambiguous within, the Git tree.

This map preserves the intended directory structure so that placeholders may later be removed from the active V1.2 repository without losing knowledge of the planned folder locations or their intended purpose.

If work later develops in one of these areas, recreate the relevant path and add substantive material there.

This document is a housekeeping record only. It is **not Concord architecture, evidence, methodology, or research content**.

## Reconstruction Principle

Removal of an `xx` placeholder will cause its otherwise empty directory to disappear from Git's visible tree. This is expected.

If one of the recorded areas becomes active later:

1. recreate the exact directory path recorded above;
2. add the first substantive file or appropriate README;
3. do not recreate the `xx` placeholder unless an empty-directory marker is again specifically required;
4. for `Simulated First-Contact Experiments`, recreate it as a directory rather than as the present one-byte file.

Frozen Concord V1.1 remains the historical repository-level record of the earlier tree. This document provides the lightweight V1.2 operational reconstruction map.
