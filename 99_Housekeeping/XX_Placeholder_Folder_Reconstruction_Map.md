## Purpose

This document records the folder and subfolder structure represented in Concord V1.2 by one-byte files named `xx`.

These `xx` files contain no substantive Concord material. Their function is solely to keep otherwise empty folders represented in Git, which does not track empty directories.

This map preserves the intended directory structure so that the `xx` placeholders may later be removed from the active V1.2 repository without losing knowledge of the planned folder locations.

If work later develops in one of these areas, recreate the relevant path and add substantive material there.

This document is a housekeeping record only. It is **not Concord architecture, evidence, methodology, or research content**.

## Reconstruction Principle

Removal of an `xx` placeholder will cause its otherwise empty directory to disappear from Git's visible tree. This is expected.

If the area becomes active later:

1. recreate the exact directory path recorded above;
2. add the first substantive file or appropriate README;
3. do not recreate the `xx` placeholder unless an empty-directory marker is again specifically required.

Frozen Concord V1.1 remains the historical repository-level record of the earlier tree. This document provides the lightweight V1.2 operational reconstruction map.
