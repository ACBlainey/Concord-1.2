## 4. PMEDG v1.1 finding classification

### Predicted findings

All principal v0.2 revision targets behaved as frozen expectations anticipated.

### Predicted pressure with novel detail

The evaluator sharpened several expected interface pressures:

1. **Natural-language “unless” semantics** — the minimum algebra works when represented as AND NOT, but the grammar should require explicit structural interpretation rather than assuming natural-language semantics.
2. **Ownership-resolution backstop/escalation** — ROUTING-UNRESOLVED needs bounded review/escalation analogous to stale-trigger hygiene.
3. **Supersession propagation/source-of-truth** — SUPERSEDED state alone cannot prevent stale replicas/downstream subscribers from acting unless integration honours it.
4. **Operational commissioning dimension** — capability provenance should allow domain distinction between laboratory validation and operational/commissioned validation.
5. **Trigger-definition review vs subject review** — temporal backstops should identify what is being reviewed.
6. **DISPUTED reconciliation follow-on** — the portable interface should make clear that DISPUTED remains routed/unresolved rather than silently terminal.

These are bounded clarification candidates.

### Wholly unpredicted findings

No wholly unpredicted mechanism defect was identified.

The useful observation that STRA's main remaining pressure lies in semantic interfaces rather than trigger classes supports convergence but is not added to the frozen score.

The independent evaluator noted that remaining defects could be frozen for a further bounded test **if T4 is desired**.

PMEDG does not require T4 for graduation. Graduation requires sufficient independent transfer evidence and convergence, not perfection or universal validation.

A third test would currently mostly test refinements already localised to interface precision:

- explicit “unless” parsing;
- ownership-resolution backstop;
- supersession propagation;
- operational capability dimensions;
- review-target typing;
- DISPUTED routing.

None currently indicates a fundamental mechanism uncertainty.

Therefore:

> **THIRD BLIND TEST NOT CURRENTLY JUSTIFIED**

A future implementation test may revisit these interfaces if operational deployment evidence warrants it.

## 7. Revision decision

Authorise a bounded v0.3 Graduation Candidate.

Required clarifications:

1. require compound natural-language conditions such as “unless” to be normalised to explicit logical structure before evaluation;
2. give ROUTING-UNRESOLVED a bounded review/escalation/backstop;
3. strengthen supersession propagation/integration requirements so stale replicas cannot legitimately reactivate superseded triggers;
4. permit capability validation scope such as laboratory/operational/commissioned without imposing one domain vocabulary;
5. type temporal backstops by review target: trigger-definition review versus subject/domain review;
6. specify that DISPUTED reconciliation remains unresolved and routes according to the host's legitimate resolution path.

Do not expand the module beyond these evidenced clarifications.
