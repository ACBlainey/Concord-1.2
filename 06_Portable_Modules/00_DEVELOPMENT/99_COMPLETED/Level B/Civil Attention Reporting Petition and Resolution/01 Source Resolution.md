## Civilisation Clock / STRA

The Civilisation Clock source family owns state/dependency/evidence/temporal review triggering. STRA adds routing-unresolved, uncertainty, stale-trigger review and bounded backstops.

Civil Attention consumes these mechanisms for queue vitality and dependency review.

> **Triggering Review ≠ Authority Over Outcome**

The portable module must specify the interface without claiming ownership of the Clock itself.

## Domain Authority

Governance, Judiciary, research, continuity, economy, emergency, privacy and other Concord domains retain their own substantive authority and specialist methods.

Civil Attention owns common intake/routing/resolution visibility, not the substantive judgment of those systems.

> **Central Visibility ≠ Central Control**

## Companion Method Boundary

Source resolution confirms that domain variation is real but does not justify divergent copies of the core method.

The required relationship is:

**Portable Civil Attention Core + Domain Companion Methodology → Domain Implementation**

The companion may add local requirements but may not override core invariants.

## Source-Relevant Tested Findings

The development programme supports the following as extraction candidates:
- one civil front door with many legitimate functional owners;
- original submission preservation;
- provisional/reviewable system classification;
- Issue Objects created when needed rather than for every submission;
- linked Domain Action Objects;
- mandatory return path;
- central resolution record;
- aggregation without treating volume as truth or priority;
- information-delta review;
- Problem State and Response State separation;
- challenge without participant command authority;
- Responsibility Resolution Object when ownership fails;
- represented cross-domain dependencies;
- Clock-driven queue vitality;
- Deferral History, Blocking Basis and meaningful review outcomes;
- protected bounded status rather than universal data access;
- individual remedy/systemic correction separation;
- urgency without truth presumption.

## Explicit Non-Ownership

The module does not own:
- substantive judicial standards;
- governance decision rules;
- emergency powers;
- domain-specific evidentiary standards;
- resource-allocation algorithms;
- identity/Sybil implementation;
- privacy/surveillance authority;
- domain staffing;
- exact timing thresholds;
- implementation UI.

These remain host/domain responsibilities or separate Concord systems.
