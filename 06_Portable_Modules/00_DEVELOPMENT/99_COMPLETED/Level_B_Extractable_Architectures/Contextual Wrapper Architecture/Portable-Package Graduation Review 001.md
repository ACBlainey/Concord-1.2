## 3. Stable portable core

The central proposition is:

> **Standardise the interface; preserve legitimate contextual variation.**

The universal primitive is the bounded context:

> **A bounded context is any distinguishable context in which some combination of access, rules, permissions, restrictions, roles, protections, responsibilities, authority, risks or expectations differs materially from another context.**

The architecture is substrate-neutral and preserves:

> **Boundary ≠ Access ≠ Rules ≠ Authority**

> **Legibility ≠ Legitimacy ≠ Consent ≠ Precedence**

> **Contextual Authority ≠ General Authority**

> **Functional Priority ≠ Personal Hierarchy**

> **Functional Permission ≠ Contextual Authority**

## 5. Precedence and authority

CWA does not claim a universal winner algorithm.

The extracted Precedence Resolution Router:

**Conflict**  
→ **Material?**  
→ **Decision Object(s)**  
→ **Permission Before Authority**  
→ **Protected Constraint?**  
→ **Protective Threshold?**  
→ **Emergency?**  
→ **Function / Competence / Responsibility / Decision Jurisdiction**  
→ **Explicit Legitimate Priority?**  
→ **Adjudicative / Jurisdictional Question?**  
→ **Jurisdiction State**  
→ **Minimum Temporary Action?**  
→ **Legitimate Resolver?**  
→ **Resolve / Route / Preserve UNKNOWN or DISPUTED**  
→ **Terminate / Revert / Review**

This is a router, not sovereignty.

---

## 6. Permission architecture

v0.3 recovered the source-present Function-Derived Permission architecture:

**Legitimate Function**  
→ **Genuine Functional Need**  
→ **Reasonably Necessary Interaction**  
→ **Minimum Necessary Permission**  
→ **Function-Bounded Activity**  
→ **Function Completion / Other Basis Ends**  
→ **Permission Terminates**

The Permission-Before-Authority Gate prevents ordinary access problems from being unnecessarily converted into power/authority problems.

## 8. Failure review

No blocking failure remains established.

Testing did not show:

- hidden personal hierarchy;
- authority manufactured from expertise;
- authority manufactured from interface structure;
- jurisdiction manufactured from externality;
- permission manufactured from self-declared need;
- private-space collapse;
- capability treated as legitimacy;
- indefinite emergency permission;
- inability to preserve unresolved states;
- inability to terminate contextual permissions/capabilities;
- absorption of the distinct interoperability problem.
