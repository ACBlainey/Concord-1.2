## 4. Remaining bounded clarifications

### 4.1 Standby CS5 versus CS6

Clarify that CS6 means the audited function is presently operational in the audited role. A tested standby that is available but not currently carrying the target function remains CS5 for recovery, even if it has demonstrated operation during testing.

### 4.2 Mixed target outcomes

Add:

> **A declared continuity target is satisfied only when all mandatory target dimensions for that audit are satisfied.**

A sub-function may independently receive C1 while the aggregate target receives C2/C7/C9.

### 4.3 MAF scope

MAF must define the complete minimum acceptable function, including any required output destination, quality, safety, provenance or other conditions supplied by the legitimate domain authority. Capacity alone does not satisfy MAF unless capacity alone was the declared MAF.

### 4.4 Criticality with alternative paths

Dependency criticality should be evaluated against the set of evidenced recovery paths. A dependency can be critical to one path while non-critical to the overall target if another sufficiently evidenced path bypasses it.

### 4.5 Classification combinations

The existing decomposition rule worked. A short clarification should state that C2/C7/C9 combinations describe different propositions and therefore do not constitute contradictory classifications.

These changes are bounded and can be integrated as v0.3 graduation-candidate clarification rather than triggering BTT-003.
