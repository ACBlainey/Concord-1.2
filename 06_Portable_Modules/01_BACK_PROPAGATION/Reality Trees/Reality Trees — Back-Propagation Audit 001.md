## Material return candidates

The portable cycle produced source-relevant refinements:

1. **Material branch distinction** — split branches where separation changes an important assumption, weighting dimension, consequence, test, action or disposition.
2. **Recursive decomposition stopping** — stop subdivision when it no longer materially changes examination, testing, action or disposition.
3. **Weight/status ≠ disposition** — what is believed/supported/contextually weighted is distinct from what the process is doing with the branch.
4. **Lightweight vs extended representation** — documentation depth should be proportional to consequence and complexity.
5. **Operational stopping checklist** — a compact test for bounded closure and later reopening.
6. **Recovered weighting distinction** — branch existence, personal belief, evidential support and contextual decision weight should not be silently collapsed into one scalar.
7. **Choice under uncertainty** — provisional action or investigation need not require epistemic collapse onto one branch.
