# Unified Paths of Light — E4
## E4-03 — Source Basis and Extraction Ledger

## Status

**ACTIVE EXTRACTION LEDGER — independent derivation phase.**

## 1. Working source basis

E4 uses the Jewish Tanakh ordering frozen in E4-01.

For primary English traversal, the experiment will use a Jewish Publication Society Tanakh translation available through a stable Jewish textual repository. Where wording materially affects extraction, alternative Jewish translations and the Hebrew text may be consulted and the ambiguity recorded.

The source repository confirms Genesis as the opening book of Tanakh/Torah and provides a complete 50-chapter traversal structure. It also provides both Hebrew and multiple Jewish English translations.

## 2. Source-use rule

Translations are evidence interfaces, not independent ethical sources.

Multiple translations of the same Hebrew passage therefore do not count as multiple occurrences.

Commentaries, topical labels and rabbinic interpretation must not be imported into primary extraction. They may be used only later where a lexical or interpretive ambiguity requires documentation, and any such use must be flagged.

## 3. Extraction numbering

Primary occurrences use:

**E4-GEN-###** — Genesis  
**E4-EXO-###** — Exodus  
**E4-LEV-###** — Leviticus  
**E4-NUM-###** — Numbers  
**E4-DEU-###** — Deuteronomy

Later books will receive equivalent stable abbreviations.

Occurrence IDs record evidence, not final principle IDs.

## 4. Ledger fields

Each extraction should preserve:

| Field | Function |
|---|---|
| Occurrence ID | Stable evidence locator |
| Passage | Scriptural location |
| Source form | Narrative / law / speech / wisdom / prophecy etc. |
| Proposition | Behavioural content recoverable from source |
| Normative status | Explicit / approved / condemned / consequence-linked / ambiguous |
| Notes | Context, ambiguity, translation or quarantine issue |
| Provisional cluster | Local working grouping only; not cross-anchor category |

## 5. Normalisation firewall

During traversal, provisional clusters are allowed only to prevent uncontrolled duplication inside E4.

They are **not** final principles.

The following remain quarantined as target taxonomies:

- E3 Q001–Q089;
- E3 A1–A10;
- Psalm synthesis;
- Blainey's Laws;
- Decalogue crosswalk;
- Ethical Topology mappings.

## 6. Genesis source-form note

Genesis is overwhelmingly narrative rather than legal material. Ethical extraction therefore relies heavily on explicit speech, explicit evaluation, condemnation, consequence-linked evaluation and clearly structured relational actions.

Mere character behaviour is not treated as normative.

This makes Genesis an immediate test of the narrative controls frozen in E4-02.

## 7. Extraction sequence

Genesis will be traversed in two audit blocks:

**Block A — Genesis 1–25**  
**Block B — Genesis 26–50**

After both blocks, a Genesis-only consolidation may be performed without consulting external anchor catalogues.

## 8. Audit principle

> **Record the ethical evidence before deciding the ethical architecture.**

This ledger is intended to preserve enough source-level information that later normalisation decisions can be reversed or audited.
