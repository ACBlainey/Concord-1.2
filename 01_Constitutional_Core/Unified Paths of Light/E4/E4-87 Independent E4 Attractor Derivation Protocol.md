# Unified Paths of Light — E4
## E4-87 — Independent E4 Attractor Derivation Protocol

## Status

**NEW BLIND COMPRESSION EXPERIMENT.**

E3 A1–A10 are re-quarantined as comparison targets. They may not be used to choose, name, merge or split E4 attractors.

# 1. Input

The only normative input is the frozen E4 catalogue J001–J034.

O-E4-01 is excluded from root clustering because it is a composition operator rather than first-order ethical content.

# 2. Experimental question

> What is the smallest stable set of higher-order functional attractors into which J001–J034 can be grouped without losing materially distinct protected interests, agency relations, epistemic requirements, institutional constraints or positive duties?

# 3. Attractor definition

An E4 attractor is not merely a topic label.

It must:
1. explain why multiple J principles recur together;
2. possess a coherent functional protected interest or constraint;
3. regenerate its child principles with domain conditions;
4. remain distinct from neighbouring attractors without hidden bridge premises;
5. survive adversarial merge pressure.

# 4. Prohibited operations

Do not:
- target ten attractors because E3 has ten;
- reuse E3 attractor names during derivation;
- use Blainey's Laws;
- use the Decalogue mapping;
- optimise for later correspondence;
- delete awkward J principles to improve elegance.

The final E4 attractor count may be lower or higher than ten.

# 5. Derivation stages

### Stage A — affinity clustering
Group J principles by shared protected interest/function.

### Stage B — parent formulation
Name the minimum functional parent capable of regenerating each cluster.

### Stage C — coverage audit
Every J001–J034 must have at least one parent.

### Stage D — overlap audit
Multiple-parent membership is permitted where a J principle is genuinely compound.

### Stage E — adversarial merge
Attempt to merge neighbouring parents. Reject any merge that destroys a distinct ethical dimension.

### Stage F — adversarial split
Test whether a parent conceals two irreducible protected interests.

### Stage G — freeze
Freeze the minimum-stable E4 attractor set before reopening E3 A1–A10.

# 6. Candidate evaluation tests

For each proposed parent ask:

- **Loss test:** what ethical information disappears if this parent is merged?
- **Regeneration test:** can the child J principles be recovered from the parent plus domain conditions?
- **Counterexample test:** can one satisfy the proposed parent while systematically violating a child in a way the parent cannot detect?
- **Boundary test:** does the parent overlap another only because concrete cases involve both?
- **Positive-duty test:** is a positive obligation being incorrectly reduced to non-harm?
- **Agency test:** is consent being incorrectly reduced to welfare?
- **Epistemic test:** is truth being incorrectly reduced to justice or harm?
- **institutional test:** is governance machinery being mistaken for a root value?

# 7. Expected output

The derivation should produce:
- provisional E4 attractors labelled JA1, JA2, ...;
- J-child mappings;
- merge/split decisions;
- unresolved edge cases;
- final frozen set.

Only after freeze may the names/content of E3 A1–A10 be reopened.

> **The target count is unknown. Convergence must be discovered, not designed.**
