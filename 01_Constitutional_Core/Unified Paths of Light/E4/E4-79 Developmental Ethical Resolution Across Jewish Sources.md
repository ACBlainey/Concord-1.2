# 2. Biblical layer

The Tanakh supplies a heterogeneous mixture:
- direct laws;
- narratives;
- prophetic criticism;
- wisdom;
- institutional history;
- relational material;
- catastrophe and repair.

Compression revealed 34 stable behavioural distinctions.

The source corpus itself already contains multiple resolutions; “biblical” therefore does not mean “simple.”

# 3. Psalmic layer

Psalms preferentially amplify:
- suffering;
- vulnerability;
- trust;
- truth/deceit;
- oppression;
- memory;
- correction;
- peace;
- wealth/status limits.

Legal-administrative detail becomes sparse because genre changes.

The holdout therefore demonstrated that **genre changes visible branches without necessarily changing roots**.

# 4. Rabbinic layer

Rabbinic reasoning frequently moves from:

[
	ext{rule}ightarrow	ext{boundary case}ightarrow	ext{distinction}
]

A proposition becomes operational by asking:
- what counts?
- what if facts are uncertain?
- what if duties collide?
- what if resources are scarce?

This is ethical decompression into jurisprudence.

# 5. Codification layer

Legal codification adds:

- implementation rules;

The ethical system becomes more executable.

# 8. Modern layer

Modern material introduces new conditions:
- industrial/institutional scale;
- persistent information systems;

The appearance of a new rule therefore does not by itself demonstrate a new root.

# 10. Connection to the Ethical Resolution Ladder

The prior Resolution Ladder can now be refined:

- **L0:** minimal ethical roots;
- **L1:** higher-order functional attractors;
- **L2:** domain principles;
- **L3:** concrete behavioural rules;
- **L4:** institutional/procedural implementations.

E4 suggests a second dimension crossing the ladder:

- **O-layer:** operators governing interaction among principles at any level.

Operators are therefore not simply another rung.

# 11. Testable implication

If this architecture is real rather than merely descriptive, then new domains should often be derivable by:

1. freezing a root set;
2. specifying domain conditions independently;
3. applying composition operators;
4. generating candidate rules;
5. comparing generated rules against an unseen mature domain corpus.

That creates a falsifiable decompression experiment.
