# Unified Paths of Light — E5
## E5-03 — Buddhist Extraction Coding Manual and Anti-Contamination Controls

## Status

**OPERATIVE EXTRACTION MANUAL.**

# 1. Purpose

This document fixes how Buddhist ethical source units will be recognised and coded before extraction begins.

# 2. Normative-status codes

### P — explicit prescription/prohibition
A behaviour is directly required, encouraged, forbidden or discouraged.

### V — explicit valuation
A behaviour or disposition is praised/blamed, skilful/unskilful, beneficial/harmful.

### C — consequence-linked norm
A behavioural pattern is connected to consequences in a way that supports an ethical proposition.

### D — developmental practice
A practice is recommended to cultivate judgement, restraint, compassion, attention or other ethically consequential capacity.

### N — narrative exemplification
A narrative clearly functions as approval, warning or ethical example.

### X — descriptive/contextual only
No separable behavioural ethical proposition. Do not enter into the normative catalogue.

# 3. Scope controls

Every ESU receives a scope marker.

### G — general agent
Potentially applicable beyond Buddhist institutional identity.

### M — monastic-specific
Depends on ordination, Sangha procedure or monastic role.

### L — lay/householder
Addressed specifically to household/social life.

### R — ruler/public authority
Concerns exercise of collective or political power.

### E — epistemic/developmental
Concerns belief, attention, judgement, correction or mental cultivation.

Multiple scope codes are permitted.

# 4. Intention-consequence matrix

Buddhist sources frequently distinguish mental intention from outward act.

Each ESU should therefore record:

| Code | Meaning |
|---|---|
| I+ | intention materially relevant |
| I0 | intention not material/unstated |
| C+ | consequence materially relevant |
| C0 | consequence not material/unstated |

This prevents later analysis from falsely reducing Buddhist ethics either to intention alone or consequence alone.

# 5. Repetition control

Repeated formulations are retained as source occurrences during extraction.

They are **not** automatically separate principles.

As in E3/E4:

> Source frequency is evidence of emphasis; it is not evidence of principle multiplicity.

# 6. Doctrinal translation control

Terms such as:
- dukkha;
- mettā;
- karuṇā;
- ahiṃsā-related formulations;
- sīla;
- paññā;
- sati;
- kamma;
- taṇhā;
- upekkhā

must not be forced into a Concord or Abrahamic vocabulary during extraction.

Record the behavioural function first.

A later normalisation stage may test functional equivalence.

# 7. Mental-state rule

An inward disposition qualifies when it has a separable behavioural or agency function.

Examples of admissible forms include:
- regulating anger before action;
- reducing craving where it drives exploitation;
- cultivating compassion where it changes treatment of others;
- attention practices that improve consequential judgement.

Purely soteriological states without separable behavioural implication remain outside the ethical catalogue.

# 8. Non-self and autonomy control

E5 must not assume either:
- that Buddhist non-self doctrine negates meaningful agency; or
- that modern autonomy concepts are present.

Extract actual rules concerning choice, coercion, responsibility, intention, refusal, dependence and development.

Interpretation comes later.

# 9. Universalisation control

A monastic rule may reveal a general ethical function, but that generalisation must be earned.

Required test:

[
	ext{institution-specific rule}
ightarrow
	ext{protected function}
ightarrow
	ext{does function survive outside institution?}
]

If no, retain as institutional application rather than root candidate.

# 10. Anti-contamination register

During extraction the researcher/AI must not consult E3/E4/Concord lists to decide:
- what to search for;
- whether an ESU is important;
- whether a cluster is missing;
- when a principle should be added;
- how many principles should exist.

Accidental recognition of similarity is unavoidable; operational use of that similarity is prohibited.

# 11. Extraction order

Begin with:

1. Dīgha Nikāya;
2. Majjhima Nikāya;
3. Saṃyutta Nikāya;
4. Aṅguttara Nikāya;
5. predefined six-book Khuddaka stratum.

This order is logistical, not hierarchical.

# 12. Extraction output

Extraction files should preserve:
- source provenance;
- uncertainty;
- awkward material;
- apparent tensions;
- narrow rules;
- repeated occurrences.

Compression is prohibited during extraction beyond local duplicate awareness.

# 13. First extraction task

E5-04 should begin **Dīgha Nikāya** extraction using the frozen coding system.

The aim is not to find familiar ethics.

The aim is to discover what the Buddhist source actually yields.
