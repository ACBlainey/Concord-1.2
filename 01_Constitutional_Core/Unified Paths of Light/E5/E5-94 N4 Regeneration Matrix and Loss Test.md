# Unified Paths of Light — E5
## E5-94 — N4 Regeneration Matrix and Loss Test

## Status
**N4 REGENERATION / ABLATION TEST.**

The architecture is tested by removing one root at a time and asking whether its distinctive rules can still be regenerated without smuggling the missing concept into another term.

| Removed root | Distinctive loss |
|---|---|
| BR1 Harm | no general prohibition on avoidable serious injury or harmful retaliation |
| BR2 Truth | no independent constraint against false or evidence-insensitive representation |
| BR3 Agency | no independent constraint against coercive domination where immediate harm is unclear |
| BR4 Care | no positive duty to aid severe need when non-intervention itself is not defined as direct harm |
| BR5 Resources | no general stewardship/legitimate possession relation beyond ad hoc harm or care cases |
| BR6 Correctability | no duty to preserve repair, reform and correction mechanisms |
| BR7 Development | no positive requirement to cultivate capability or scale responsibility to capacity |
| BR8 Integrity | no independent entrusted-role constraint against status/reward capture when statements remain literally true |

## Operator ablation
Removing operators does not usually erase ethical direction, but it predictably degrades application quality:
- no BO1 → symptom treatment;
- no BO2 → short-horizon/local optimisation;
- no BO3 → brittle, non-learning ethics;
- no BO4 → over/under-response;
- no BO5 → suppression without replacement;
- no BO6 → identity/attachment capture;
- no BO7 → semantic drift;
- no BO8 → performative ethics.

## Regeneration check
Representative source-level rules remain regenerable:
- killing restraint: BR1;
- truthful speech: BR2 + BR1;
- non-exploitative relationship: BR3 + BR1 under BC1;
- support for dependants: BR4 + BR7 under BC1;
- non-taking/stewardship: BR5 + BR3;
- reform after wrongdoing: BR6 + BO3;
- graduated instruction: BR7 + BO4 under BC5;
- anti-status corruption of teacher/role: BR8 + BR2 + BO8 under BC2/BC9.

## Finding
All eight roots pass first-order ablation at N4 resolution.
