# N5 minimum-stability protocol

A root may be removed only if every distinctive behavioural obligation it generates can be reconstructed from the remaining architecture **without**:
1. redefining another root to secretly contain it;
2. losing a source-supported behavioural distinction;
3. turning a positive duty into mere permission;
4. converting an ethical constraint into an optional operator;
5. relying on an external comparison framework.
