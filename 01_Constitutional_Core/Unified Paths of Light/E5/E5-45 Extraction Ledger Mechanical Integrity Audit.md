## 3. Resolution mismatch detected

The audit confirms an important methodological asymmetry:

**DN/MN extraction is generally discourse-oriented.**

**SN/AN extraction is substantially coarser and thematic/book-oriented.**

This does not invalidate the first pass, but it means the corpus cannot yet be described as mechanically exhaustive at equivalent resolution.

## 4. Identifier issue

Earlier files use several identifier families and later coarse-range records sometimes preserve range rather than individual passage provenance.

This is acceptable for exploratory extraction but **not sufficient for publication-grade traceability**.

Required repair:
- preserve existing occurrence IDs;
- add canonical passage IDs where recoverable;
- mark records that represent repeated families rather than a single passage;
- never fabricate precision where the first pass did not record it.

## 5. Count discipline

No total primary-corpus occurrence count is frozen in this audit.

Reason: a raw count across mixed extraction resolutions would create false numerical precision.

Counts may be frozen only after the provenance audit establishes a consistent counting rule.

## 6. Contamination audit

No deliberate E3/E4/Concord crosswalk appears in the E5 extraction logic.

Some functional vocabulary inevitably resembles earlier work, but no source record is to be retained merely because it matches a prior principle.
