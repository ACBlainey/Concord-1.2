# Unified Paths of Light — E9

## E9-776 — Repository-Bitstream Identity Rule

A repository bitstream URL may be admitted as T0 only if its identity is tied to the frozen Christaller 1879 item by at least one reliable mechanism:

- item-page file link;
- repository API metadata;
- matching filename plus item identifier;
- or direct inspection demonstrating the Christaller title/edition.

Search-engine proximity is insufficient. This rule prevents accidentally processing a thesis or later paper that merely cites Christaller.
