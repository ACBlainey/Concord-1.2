# Unified Paths of Light — E9

## E9-1198 — Parent-Child Compression Register 023: AR484–AR504

### Existing parents extended

**PC-P052 — indirect signalling**
- AR485 — vulnerable agents may strategically under-disclose need.

**PC-P093 — coercive amplification/accountable authority**
- AR486 — authority-holders bear responsibility to prevent misuse carried out through associated power.

**PC-P051 — safe exploration**
- AR487 — uncertain investigation should preserve a support/safety margin.

**PC-P056 — manufactured vulnerability**
- AR488 — creating dependency/exposure and then exploiting it is defective because the exploiter helped create the vulnerability.

**PC-P010 — assistance and receiving capability**
- AR489 — assistance requires a functioning receiving mechanism.
- AR504 — distributed teaching/support can correct ignorance through others.

**PC-P024 / PC-P080 — opportunity windows**
- AR490 — enabling resources should be secured before access closes.
- AR491 — searching indefinitely for the optimum can consume the useful opportunity window.

**PC-P042 — concealment and disclosure**
- AR492 — concealment is defeated by observable inconsistency/revealing action.

**PC-P049 / PC-P094 — recoverability and repair**
- AR493 — initial failure should not trigger destruction where the system remains useful/recoverable.

**PC-P002 — learning from failure**
- AR494 — regret/experience should inform later action.

**PC-P011 — context-sensitive participation**
- AR495 — conduct can vary appropriately with social setting.

**PC-P007 — local knowledge and authority**
- AR497 — unsupported outsider authority should not displace embedded local knowledge.

**PC-P091 — legitimacy**
- AR498 — outsider status cannot self-create supreme local authority.

**PC-P059 / entitlement**
- AR499 — beneficiary/requester status does not confer allocation authority.

**PC-P046 — indispensable components**
- AR503 — a necessary component should not be excluded merely because it is small or subordinate.

### New provisional parent

**PC-P101 — Exploration as information generation**
- AR500 — exploratory exposure can generate returned information about uncertain conditions.

PC-P101 is a sibling of PC-P051's safe-exploration constraint: one explains epistemic benefit, the other the safety condition.
