# Unified Paths of Light — E9
## E9-15 — Extraction Hold Gate and Resolution Path

## Gate decision
E9-A will **not** begin ethical extraction merely because the primary source images are available.

The experiment is held until a defensible translation path is established.

## Acceptable resolution
Extraction may begin when at least one of the following is available:

### Route A — aligned published translation
A legitimate accessible copy of the 1990 Kofi Ron Lange translation, or another sufficiently complete scholarly translation aligned to Christaller's corpus.

### Route B — source-language competence layer
A reliable Twi/Akan translation workflow with independent lexical/grammatical checks sufficient to prevent the AI's own unconstrained translation from becoming the evidence.

### Route C — revised independently frozen corpus
If A and B prove infeasible, E9 may prospectively replace the primary corpus with another broad Akan collection that supplies adequate source-language/translation pairing.

This route requires a formal boundary amendment **before extraction**, with the reason recorded as accessibility/method validity rather than ethical outcome.

## Prohibited resolution
E9 must not:
- use web searches for expected ethical themes as a substitute corpus;
- select only famous translated Akan proverbs;
- translate only items that appear likely to contain expected roots;
- use modern summaries to fill gaps;
- abandon difficult items selectively.

## Current state
No E9 ethical occurrence has been coded.

The prospective predictions remain untouched.
