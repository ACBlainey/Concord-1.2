# Unified Paths of Light — E9

## E9-1170 — Parent-Child Compression Entry Protocol

### Purpose

The next stage asks a different question from duplicate consolidation.

Duplicate audit asked:

> Can one proposition be removed because another preserves all meaningful ethical information?

Parent-child compression asks:

> Can multiple genuinely distinct propositions be represented as differentiated children of a more general internally derived parent without losing their distinctions?

### Input

The frozen input is the **557-proposition overcomplete Akan catalogue** established by E9-1169.

### Rules

1. **No external architecture.** The semantic firewall remains closed.
2. **No target count.** Compression must stop where further abstraction would erase meaningful function.
3. **Children remain recoverable.** A parent never deletes the distinctions that justified retaining its children during duplicate audit.
4. **Parents must be induced internally.** A parent is justified only by the propositions beneath it, not by resemblance to prior E-series roots.
5. **Mechanism matters.** Similar outcomes with materially different mechanisms may require separate intermediate parents.
6. **Reference point matters.** Agent-, relationship-, population-, function-, domain-, status- and time-relative propositions should not be collapsed merely because they share vocabulary.
7. **Compound propositions may map to more than one candidate parent** until architecture separation resolves them.
8. **HOLD is valid.** Ambiguous parentage should remain explicit rather than forced.
9. **Compression is iterative.** Begin with local neighbourhoods, then test whether intermediate parents themselves admit higher-order grouping.
10. **Root discovery occurs only after lower-level structure is visible.**

### Working relation classes

Each proposition-to-parent decision should be marked:
- **CHILD** — clear specialisation of parent;
- **SIBLING** — related but not subordinate;
- **BRIDGE** — legitimately connects multiple candidate parents;
- **INDEPENDENT** — no justified parent in current pass;
- **HOLD** — relation remains uncertain.

### First-pass neighbourhoods

The descriptive neighbourhoods already observed during normalisation may be used only as search aids, not as predetermined parents:
- harm / hazard / vulnerability / protection;
- agency / dependency / coercion / effective choice;
- evidence / truth / causal attribution / correction;
- capability / development / learning / assistance;
- resource / scarcity / stewardship / allocation;
- relationship / reciprocity / care / obligation;
- authority / status / hierarchy / accountability;
- privacy / communication / information boundaries;
- collective coordination / systems / continuity / resilience;
- context / function / domain / reference-point evaluation.

These labels remain provisional.

### Immediate next operation

Construct the first parent-child compression register from the beginning of the frozen catalogue, retaining exact proposition identifiers and explicitly distinguishing local parent induction from higher-order architecture.
