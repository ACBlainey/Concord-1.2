# Unified Paths of Light — E9

## E9-814 — T0 External-Acquisition Handoff Boundary

A complete Christaller file obtained outside the current execution path may be ingested without changing methodology.

Accepted handoff objects:
- public-domain PDF of the 1879 Christaller book;
- EPUB containing faithful page/text representation;
- ordered page-image package;
- verified LoC/UGSpace/Google export of the same 1879 object.

On receipt, execute E9-808 before corpus extraction. A user-supplied file does not need to reproduce the original download route if edition identity can be verified internally.
