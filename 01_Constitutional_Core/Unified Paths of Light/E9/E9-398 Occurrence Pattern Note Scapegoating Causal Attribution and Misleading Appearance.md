# Unified Paths of Light — E9

## E9-398 — Occurrence Pattern Note: Scapegoating, Causal Attribution and Misleading Appearance

R695 and R702 form a strong attribution pair.

R695: the fetish priest is killed whether rain falls or does not fall. The accountable agent is blamed under mutually incompatible outcomes, making successful performance incapable of producing exoneration.

R702: an already failing crop can be walked through with a “bad charm,” creating an appearance that invites blame for a failure that was going to occur anyway.

The shared problem is **causal attribution detached from discriminating evidence**.

Two failure modes appear:
- outcome-independent scapegoating;
- misleading temporal/visual association with a pre-existing failure.

A fair responsibility system therefore needs some way to distinguish genuine causal contribution from mere association and from roles constructed so that blame is unavoidable.
