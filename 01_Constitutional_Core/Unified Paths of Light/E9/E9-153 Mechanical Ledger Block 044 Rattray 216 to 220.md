## E9-153 — Mechanical Ledger Block 044: Rattray 216–220

216 / C1654 = H — an ordinary fowl hatches a ruffled-feather chicken, which wonders where it alone came from. Difference within a common lineage is visible, but the source supplies no sufficiently explicit transferable ethical application.

217 / C1656 = Y — the fowl proposes plucking the tortoise, and the tortoise replies that the fowl will tire of trying. Some protective properties make attempted exploitation or attack prohibitively costly to sustain.

218 / C1660 = Y — Rattray explicitly explains that the fowl's head is too small to justify striking it if one does not intend to kill the animal altogether. Force must be proportionate to the vulnerability of the target and the intended outcome.

219 / C1670 = Y — the cock is told to desist from self-glorification because all are children of eggs. Shared basic origin undermines claims to inflated superiority.

220 / C1641 (OCR renders 1G41) = Y — one need not hurry to search for the fowl that shares one's hut because it will predictably return to roost. Reliable recurrence can justify restraint rather than unnecessary urgent pursuit.

**Minimal function:** Protective characteristics can make attempted exploitation or attack sufficiently costly that persistence becomes ineffective.
**Confidence:** high.

### AR106 — Rattray 218 / Christaller 1660

**Confidence:** very high because Rattray supplies the explicit explanation.

### AR107 — Rattray 219 / Christaller 1670

**Confidence:** high.

### AR108 — Rattray 220 / Christaller 1641
