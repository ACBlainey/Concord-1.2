# Unified Paths of Light — E9

## E9-399 — Occurrence Pattern Note: Context-Relative Evaluation and Total Effects

R689, R703, R704 and R705 reinforce the source's resistance to context-free evaluation.

R689: water inadequate for bathing can be adequate for drinking — adequacy depends on function.

R703: an apparent comfort can fail to benefit when accompanied by a contrary harmful element — evaluation requires the whole intervention.

R704: the same event can be bad for one agent and good for another — outcome depends on affected party.

R705: the same person can be judged differently by different parties — relational experience affects evaluation.

These occurrences should not be collapsed into relativism. They instead require the evaluator to specify:
- function;
- complete effect bundle;
- affected agent;
- relationship/context.

The recurring source demand is greater precision about **what is being evaluated, for whom, and under which conditions**.
