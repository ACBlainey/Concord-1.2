# Unified Paths of Light — E9

## E9-897 — Cadence Reliability Rule

The repository workflow may continue using up to 15 substantive writes per working batch, but a batch is complete only when each individual commit is confirmed.

A tool-side interruption does not invalidate prior successful commits and does not authorize skipping uncommitted document numbers. Numbering resumes from the first uncommitted document.
