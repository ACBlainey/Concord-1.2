# Unified Paths of Light — E9
## E9-44 — Mechanical Reconstruction Block Size and Checkpoint Protocol

## Purpose
Define the work pattern now, so block size cannot later be adjusted to hide difficult material or apparent saturation.

## Protocol
Once full source access is available:
- traverse strictly in printed order;
- process fixed sequential blocks;
- record every item as Y, Z, H or X;
- retain item locator and chapter;
- instantiate AR occurrences only from Y items;
- reconcile each block before advancing.

## Checkpoints
At each checkpoint report:
- source range;
- items processed;
- Y/Z/H/X arithmetic;
- AR occurrences instantiated;
- unresolved translation/context debt;
- continuity check to next source item.

## Saturation
Novelty decline does not terminate traversal.

## Architecture firewall
No root normalisation begins during mechanical reconstruction, even if recurring functional patterns become obvious.
