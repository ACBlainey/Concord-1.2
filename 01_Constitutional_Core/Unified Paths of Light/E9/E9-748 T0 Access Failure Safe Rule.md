# Unified Paths of Light — E9

## E9-748 — T0 Access Failure-Safe Rule

A catalogue record, search-result snippet, bibliographic citation, or inaccessible PDF link is **not** sufficient evidence for an individual Christaller inventory row.

If a T0 page cannot be directly inspected:
- record access status;
- do not infer item numbers;
- do not import Rattray wording as if it were Christaller wording;
- do not manufacture C-only rows;
- continue only with infrastructure or another independently visible T0 witness.

This rule extends the source-integrity lessons from the earlier Rattray ledger failures to the Christaller expansion phase.
