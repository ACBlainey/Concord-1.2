# Unified Paths of Light — E9

## E9-764 — Library of Congress IIIF Route Reassessment

The Library of Congress item page explicitly exposes an **IIIF Presentation Manifest** in addition to PDF and image formats.

### Acquisition implication
The IIIF route is now promoted as the preferred technical path for page-level access because a manifest can, in principle, enumerate canvases and image services without relying on the interactive viewer.

### Integrity rule
Manifest metadata may establish canvas order and image locators. Individual proverb transcription still requires inspection of the actual canvas/image content.
