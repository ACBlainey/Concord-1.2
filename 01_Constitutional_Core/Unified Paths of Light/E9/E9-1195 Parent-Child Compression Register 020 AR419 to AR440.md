# Unified Paths of Light — E9

## E9-1195 — Parent-Child Compression Register 020: AR419–AR440

### Existing parents extended

**PC-P061 — Preference and interpretation distortion**
- AR420 — inaccessible goods can be devalued in stated preference.
This complements AR161 abundance-conditioned preference and AR257 post-failure reinterpretation.

**PC-P008 / PC-P059 — functional resource value and surplus**
- AR422 — resource value depends on usable function rather than possession alone.
- AR423 — available strategies depend on surplus/capacity.
- AR424 — desire alone does not create a causal pathway to a scarce resource.
- AR425 — productive use can regenerate or expand resources.

**PC-P029 — stewardship of sustaining conditions**
- AR427 — delayed stewardship reduces adaptive margin.
- AR428 — active management preserves retained resources.
- AR430 — hoarding can defeat a resource's functional purpose.
- AR431 — refusing necessary expenditure can defeat an independently chosen objective.

**PC-P012 — status-conditioned interpretation**
- AR433 — advantage/status can produce lenient description.
- AR435 — high status can insulate an agent from negative attribution.
- M006/AR436 — opposed positions can both be condemned, creating an evaluative double bind.

**PC-P051 — hazard management**
- AR439 — prior exposure can alter later susceptibility.
- AR440 — an agent should not transfer its own hazard onto a vulnerable party.

### New provisional parents

**PC-P095 — Precursors and anticipatory action**
- M007 (AR437+AR462) — consequential events can produce observable precursors permitting anticipation.

**PC-P096 — Resource purpose and enabling expenditure**
- AR430 — resources should not be retained in ways that defeat their inherent purpose.
- AR431 — necessary expenditure can be required to realise a chosen objective.

These are siblings beneath a use-oriented resource parent; neither is reducible to the other.
