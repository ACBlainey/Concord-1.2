# Unified Paths of Light — E9

## E9-921 — Parser-Recovery versus Ledger-Exception Rule

For each exceptional relation, the question is binary:

1. Is its reconciled C-ID already present as the correct R→C edge in Pass 001? If yes, it contributes zero to the residual gap.
2. Is it absent from Pass 001? If yes, add exactly that missing edge.

This rule is especially important for OCR forms such as `2G56`, `G 1 6`, `27G0`, `174G`, `1G51` and `218G`, because the widened parser was intentionally capable of conservative `G→6` and spacing normalisation.
