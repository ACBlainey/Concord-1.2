# Unified Paths of Light — E9

## E9-1228 — Parent Inventory Consolidation Register 020: Context, Reference Point and Comparative Evaluation

### Higher internally derived parents

**HC-P048 — Evaluation requires the relevant reference point**

Subsumes:
- PC-P067 — category equality does not imply property identity;
- PC-P086/M010 population-relative consequence structure;
- AR205/286/451/452/457/470/472/557.

Core structure:
> Evaluation should specify the relevant agent, population, function, domain or comparison class because the same object, event or property can have different significance under different reference points.

**HC-P049 — Context can alter appropriate conduct without erasing underlying constraints**

Subsumes:
- PC-P011 — context-sensitive participation;
- M003 local-practice adaptation;
- AR062/163/495;
- scarcity-conditioned substitution where context changes feasible implementation.

Core structure:
> Appropriate conduct can vary with local practice, social setting and material conditions while remaining answerable to the function or constraint being implemented.

**HC-P050 — Situated position changes epistemic access**

Subsumes:
- PC-P007 — situated knowledge/environment;
- M001 local embedded knowledge;
- AR306/320/322/497.

Core structure:
> What an agent can know depends partly on its relation to the environment, community or practice; general observational ability does not erase the epistemic advantages or limitations of situated access.

### Boundary

HC-P048 concerns the **reference point of evaluation**.  
HC-P049 concerns **context-sensitive conduct**.  
HC-P050 concerns **context-sensitive knowledge**.

The corpus repeatedly distinguishes these, so they remain separate.
