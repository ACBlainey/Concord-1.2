# Unified Paths of Light — E9

## E9-752 — T0 Page-Count Reconciliation

The Library of Congress catalogue describes the physical book as **xii + 152 pages**, while its digitised-object interface reports **172 image results**.

These counts are not contradictory: physical pagination and digitised image/canvas count need not coincide because covers, flyleaves, title matter and other unnumbered leaves may be included in the scan.

### Control consequence
Christaller printed page number must not be equated mechanically with LoC image sequence number until an explicit offset is established from visible pages.
