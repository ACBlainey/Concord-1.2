# Unified Paths of Light — E9

## E9-812 — LoC Resource-Namespace Reconciliation

Search results expose two closely related LoC resource forms for the same LCCN 43019087 object: `gdc.43019087` and `gdclccn.43019087`.

### Rule
These strings are retained as observed LoC routing/resource labels only. Neither is promoted to a IIIF image identifier without direct metadata evidence.

This preserves E9-773's prohibition on synthesising tile/image-service identifiers from catalogue identifiers.
