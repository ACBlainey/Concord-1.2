# Unified Paths of Light — E9

## E9-389 — Occurrence Pattern Note: Resource Function, Context and Lifecycle

R668, R674, R683 and R684 add useful distinctions to the earlier stewardship material.

R668: immediately useful resources are preferentially selected.

R674: a resource that eventually becomes waste can still have had legitimate prior value.

R683: a resource need not possess irrelevant qualities to perform an urgent function — clear water is unnecessary for extinguishing fire.

R684: the same substance can sustain and endanger depending on context.

This yields a lifecycle/context view of resources:
- value depends on function;
- use can transform resource state;
- eventual exhaustion does not retroactively erase prior value;
- suitability is task-specific;
- a resource has no single context-independent risk/benefit classification.

This may later be important when distinguishing stewardship from simple preservation.
