# Unified Paths of Light — E9

## E9-1183 — Parent-Child Compression Register 010: AR195–AR221

### Existing parents extended

**PC-P046 — Critical enabling infrastructure**
- AR195 — a small enabling component can be indispensable to system function.
- AR204 — user-facing protective infrastructure can preserve safe operation.

**PC-P002 — Experience-mediated correction and guidance**
- AR201 — correction/development fails where the learner is unreceptive.
- AR207 — development benefits from receptivity to experienced guidance.
- AR220 — testing exposes bounded capability.
- AR221 — immediate consequence can correct a dangerous misunderstanding.

This now separates **experience availability** from **receptivity to correction**.

**PC-P001 — Performance-grounded capability assessment**
- AR203 — capability depends on target properties/resistance.
- AR208 — demonstrated capability can justify expanded participation.
- AR219 — forceful temperament or signalling does not itself establish effective capability.

**PC-P008 — Reference-dependent sufficiency**
- AR205 — sufficiency depends on recipient scale/need.
This is retained for later comparison with AR457's function-relative sufficiency.

**PC-P024 — Timing-sensitive continuity**
- M014/AR210 is anticipated only as the already frozen canonical proposition: intergenerational transmission sustains continuity.

### New provisional parents

**PC-P049 — Proportionate correction and repair**
- M011/AR198 — correctable degradation should invite proportionate repair rather than destruction.
- AR228 later provides a governance analogue.

**PC-P050 — Impartial accountability**
- AR200 — favour or relationship should not exempt harmful/dishonest conduct.
- AR213 — role participation can carry role-linked responsibility.
- AR214 — task participation can carry task-linked risk/responsibility.

**PC-P051 — Reversibility-preserving hazard management**
- AR216 — self-generated exposure can create avoidable hazard.
- AR239 later supplies preservation of escape/reversibility.

**PC-P052 — Behaviour as evidence of latent state**
- AR217 — behaviour can evidence unspoken need, expectation or intention.
- AR265 later tests costly unusual behaviour as stronger evidence.
