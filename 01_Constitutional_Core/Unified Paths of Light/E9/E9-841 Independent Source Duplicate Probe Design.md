# Unified Paths of Light — E9

## E9-841 — Independent Source Duplicate Probe Design

To test the overlap-ledger cardinality independently, the primary local Rattray OCR witness was scanned mechanically for proverb-header lines containing parenthetical numeric Christaller references.

The probe deliberately used the source witness rather than the cumulative overlap arithmetic. It normalised only spacing and obvious OCR `l/I→1` inside otherwise numeric parenthetical identifiers. It did not infer missing identifiers or repair arbitrary damaged strings.

This is an independent duplicate-detection probe, not yet a complete reconstruction of all 830 mappings.
