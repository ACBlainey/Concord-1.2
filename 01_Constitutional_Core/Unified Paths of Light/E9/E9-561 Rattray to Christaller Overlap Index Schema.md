# Unified Paths of Light — E9

## E9-561 — Rattray-to-Christaller Overlap Index Schema

The mechanical overlap index is now formally opened.

### Unit
One Rattray numbered item mapped to the parenthetical Christaller identifier printed with it.

### Fields
R-ID | C-ID-RAW | C-ID-RECONCILED | source locator | duplicate C-ID? | variant note | identifier debt | confidence.

### Rules
- identifiers are transcribed, not inferred;
- same C-ID appearing under multiple R-IDs is retained as a duplicate relation, not silently collapsed;
- OCR anomalies remain visible;
- reconciled identifiers require evidence;
- the index contains no ethical classification.

### Purpose
The completed index will define which Christaller items are already represented in the closed Rattray subset and which are candidates for C-only expansion.
