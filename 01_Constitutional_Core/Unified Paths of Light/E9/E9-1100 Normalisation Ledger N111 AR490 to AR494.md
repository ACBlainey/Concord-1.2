## E9-1100 — Normalisation Ledger N111: AR490–AR494

| AR | Source | Normalised ethical proposition | First-pass relation note |
|---|---|---|---|
| AR490 | R729 / C172 | Available enabling resources should be recognised and secured while they remain accessible rather than sought only after the opportunity has passed. | Opportunity-sensitive preparation. |
| AR491 | R730 / C182 | Search for an optimum solution can become self-defeating when delay consumes the period in which any solution would have value. | Optimisation / timeliness trade-off. |
| AR492 | R731 / C185 | Concealment can be defeated by actions that generate observable evidence inconsistent with remaining hidden. | Behavioural evidence / concealment failure. |
| AR493 | R732 / C186 | An initial failure should not automatically trigger destruction or abandonment of a still-useful resource or system. | Corrective restraint / recoverability. |
| AR494 | R733 / C189 | Experience of avoidable regret should inform later action; repeated error without correction wastes information gained from prior failure. | Learning from failure. |

AR490–AR491 strengthen the temporal dimension of effective action: a technically superior option can lose practical value if enabling resources or the opportunity window expire first.
