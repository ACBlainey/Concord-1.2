# Unified Paths of Light — E9

## E9-219 — Occurrence Pattern Note: Tools, Components, Operators and Realised Capability

R329, R332, R336 and R339 provide a compact systems-capability sequence.

- R329: protective infrastructure preserves gun function in rain.
- R332: the gun requires an operator.
- R336: failure of a critical lock reduces the gun functionally to a stick.
- R339: a small flint-stone enables the larger weapon's performance.

The source therefore distinguishes nominal possession of a tool from **realised capability**, which depends on:
1. environmental protection;
2. an activating agent;
3. functioning critical subsystems;
4. small enabling components.

This is potentially important for later systems compression, but the firewall remains closed.
