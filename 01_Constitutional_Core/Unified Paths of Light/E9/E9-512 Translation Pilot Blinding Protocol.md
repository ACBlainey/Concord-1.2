# Unified Paths of Light — E9

## E9-512 — Translation Pilot Blinding Protocol

The pilot must distinguish translation generation from reference comparison.

### Translation phase
For each frozen item:
1. expose only the Twi/source text and minimal orthographic context;
2. do not expose Rattray's English rendering to the translation step;
3. generate a conservative English rendering;
4. mark uncertain lexical or grammatical elements;
5. prohibit ethical interpretation from repairing the translation.

### Comparison phase
Only after the candidate rendering is fixed:
1. reveal Rattray's translation;
2. score the candidate against the frozen E9-504 dimensions;
3. inspect Rattray commentary where needed;
4. triangulate disagreements with T1/T3 where accessible.

### Important limitation
The current local witness interleaves Twi and Rattray English. Therefore the human/AI workflow must enforce conceptual blinding even though both layers exist in the same file.

A future automated test should extract Twi into a separate temporary validation sheet before translation.
