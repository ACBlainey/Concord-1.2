# Unified Paths of Light — E9

## E9-527 — Raw Versus Normalised Twi Control

The pilot source recovery reveals a distinction that should be formalised.

### RAW field
Exact working-witness OCR as retrieved.

### NORMALISED field
Optional corrected transcription produced only when:
- the correction is mechanically obvious; or
- a page image/independent witness supports it.

### Rule
Never overwrite RAW.

Every normalisation must record:
- changed token;
- reason;
- evidence;
- confidence.

### Translation use
Where RAW corruption is material, the candidate translator may receive NORMALISED text only if the repair was fixed before reference-English comparison.

Otherwise the item carries translation debt.

### Benefit
This separates translation performance from OCR-repair performance and prevents the model from being penalised—or falsely credited—for guessing corrupted source text.
