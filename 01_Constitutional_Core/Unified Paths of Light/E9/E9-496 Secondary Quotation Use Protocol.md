# Unified Paths of Light — E9

## E9-496 — Secondary Quotation Use Protocol

Scattered Lange translations occur in scholarly literature.

These can be useful, but they must not become an uncontrolled substitute for T1.

### Permitted use
A secondary quotation may establish an item-level translation only when:
1. the Christaller number is explicit;
2. the quoted English wording is attributed to Lange;
3. the source is identifiable;
4. the quotation is sufficiently complete for the proposed abstraction.

Such an item is marked **T1-via-secondary quotation**, not direct-T1 access.

### Prohibited use
Do not:
- infer translations for neighbouring C-IDs;
- reconstruct missing Lange wording from paraphrase;
- treat an author's interpretation as Lange's translation;
- use page references without C-ID as proof of alignment where ambiguity remains.

### Role
This route is appropriate for spot validation and triangulation, not for pretending the entire 3,600-item corpus has been translated into the working environment.
