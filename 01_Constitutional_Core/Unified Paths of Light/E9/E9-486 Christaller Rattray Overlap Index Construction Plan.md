# Unified Paths of Light — E9

## E9-486 — Christaller–Rattray Overlap Index Construction Plan

The closed Rattray corpus contains 830 entries, each associated with a visible or source-reconciled Christaller identifier.

These mappings now become a deduplication index.

### Construction
Build a set of all Christaller identifiers represented by R1–R830.

For each Christaller item encountered in T0:
- if C-ID occurs in the set, mark **R-overlap**;
- attach the corresponding R number;
- inherit no new ethical count merely from re-encountering the item;
- compare wording/variant only where useful.

If the C-ID is absent:
- mark **C-only candidate**;
- send through translation gate;
- only then permit ethical extraction.

### Important distinction
Rattray's numbering is not Christaller's ordering. Rattray regrouped selected proverbs thematically, whereas Christaller's collection is alphabetically arranged.

Therefore sequential expansion must follow Christaller's own printed structure, not Rattray order.
