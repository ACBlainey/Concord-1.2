# Unified Paths of Light — E9

## E9-1241 — Architecture Separation Register 005: Provisional Substantive Parent Set

### Derivation

After classifying HC-P001–HC-P053 by architectural role, **23 HC structures** remain primary substantive-orientation candidates.

They are not yet roots and are not yet minimally compressed.

### Provisional substantive set

**Development / truth / communication**
- SP01 — capability should be developable and correctable (HC-P004)
- SP02 — representation should remain answerable to reality (HC-P007)
- SP03 — communication should be fitted to recipient and purpose (HC-P010)
- SP04 — legitimate information boundaries should be respected (HC-P011)

**Agency / power / responsibility / protection**
- SP05 — agency requires practically viable choice (HC-P013)
- SP06 — residual agency should persist under constraint and assistance (HC-P015)
- SP07 — vulnerability should not be created or exploited (HC-P017)
- SP08 — authority requires a legitimate basis beyond self-assertion (HC-P018)

- SP11 — foreseeable serious harm supports preventive restraint (HC-P021)
- SP12 — protection should be vulnerability-sensitive (HC-P022)
- SP13 — harm should not be displaced onto vulnerable or uninvolved parties (HC-P023)

**Relationship / care / reciprocity**
- SP14 — relationships can generate differentiated obligations of support (HC-P025)
- SP15 — reciprocity should remain responsive to asymmetry (HC-P026)
- SP16 — durable relationships should not be treated as purely replaceable instruments (HC-P027)
- SP17 — care obligations should be vulnerability- and capability-sensitive (HC-P028)

**Resources / claims**
- SP19 — resource judgment should track functional use and actual sufficiency (HC-P031)
- SP20 — desire, association or abundance do not by themselves create entitlement (HC-P035)
- SP21 — productive contribution and causal role can ground differentiated claims (HC-P036)

**Continuity / adaptation**
- SP22 — continuity requires preservation of enabling conditions across time (HC-P041)
- SP23 — adaptation should preserve function while responding to changed conditions (HC-P046)

### Important caution

Twenty-three is a **provisional substantive-parent count**, not an ethical-root count.

Many SP items may still be:
- siblings under a deeper substantive orientation;
- domain expressions of a deeper root;
- compounds containing an orientation plus operator;
- culturally specific branch structures.

The next step is recoverability and minimum-stability testing.
