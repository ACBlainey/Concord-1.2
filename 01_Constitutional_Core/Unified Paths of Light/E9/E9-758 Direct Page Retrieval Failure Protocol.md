# Unified Paths of Light — E9

## E9-758 — Direct Page Retrieval Failure Protocol

When an indexed T0 page exists but retrieval fails because of HTTP, viewer, anti-bot or execution-environment restrictions:

- classify the event as **ACCESS**, not textual uncertainty;
- retain the exact witness/page locator;
- try the next frozen independent witness;
- never convert search snippets into full inventory rows;
- never OCR a search-engine thumbnail when a primary scan remains obtainable elsewhere;
- do not relax the translation gate.

This prevents infrastructure limitations from becoming corpus claims.
