# Unified Paths of Light — E9

## E9-558 — Pilot Decision Matrix

### Outcome A — ≥90% materially clean
T4 may be activated as a controlled translation route for C-only items, subject to item-level debt and triangulation.

### Outcome B — <90% materially clean
T4 is not authorised as the primary C-only route.

Response options:
- strengthen lexical aids;
- create a new predeclared Class B run;
- seek broader T1 access;
- increase T3 alignment;
- obtain linguistic review.

### Outcome C — too many unscorable OCR cases
The test diagnoses source quality rather than translation quality.

Repair/verify source transcription first, then run a new version.

### Outcome D — contamination discovered
Exclude the run from the blinded statistic and repeat independently.
