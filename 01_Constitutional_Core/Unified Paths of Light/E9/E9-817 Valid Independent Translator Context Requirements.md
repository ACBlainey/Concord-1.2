# Unified Paths of Light — E9

## E9-817 — Valid Independent-Translator Context Requirements

A valid independent run requires a context/process that receives:
- only E9-TVP-SOURCE-v1.0 source rows;
- the frozen translator prompt;
- optional declared lexical resources according to run class;
- no Rattray/Lange answer-key English before candidate freeze.

The translator need not know the wider E9 ethical hypotheses. Minimising contextual exposure is preferred because it reduces semantic steering.
