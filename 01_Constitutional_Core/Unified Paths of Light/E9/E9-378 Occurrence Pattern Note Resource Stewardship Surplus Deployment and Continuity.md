# Unified Paths of Light — E9

## E9-378 — Occurrence Pattern Note: Resource Stewardship, Surplus, Deployment and Continuity

R650–660 contain a compact resource-management architecture.

R650 distinguishes subsistence resources from surplus: resources needed for one's own basic requirements are not available for lending.

R652 depicts surplus resource deployment producing additional return.

R655 shows prudence emerging as depletion becomes visible.

R657 says resources can be lost if not actively looked after.

R658 distinguishes possessing wealth from solving succession.

R659 and R660 show the opposite failure mode: excessive reluctance to spend can defeat the purpose for which resources are held.

The sequence therefore avoids both simple accumulation and simple expenditure. It describes stewardship as balancing:
- minimum retained capacity;
- productive deployment of genuine surplus;
- active maintenance;
- anticipation of depletion;
- continuity/succession;
- willingness to spend when expenditure is necessary for function.
