# Unified Paths of Light — E9

## E9-127 — Occurrence Pattern Note: Substance Over Appearance

R171 adds to a recurring E9 distinction between appearance/label and actual function.

The snake resembles rope but cannot therefore be treated as rope. This joins earlier occurrences in which:
- visible diminution did not erase capacity;
- physical magnitude did not determine practical standing;
- awkward appearance did not negate effectiveness;
- similar names did not establish substantive equivalence.

The repeated functional structure is that assessment should respond to actual properties, capability and consequences rather than surface resemblance alone.

This remains a recurrence note, not a compressed root.
