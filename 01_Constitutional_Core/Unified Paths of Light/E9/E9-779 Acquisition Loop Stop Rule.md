# Unified Paths of Light — E9

## E9-779 — Acquisition-Loop Stop Rule

Repeatedly documenting the same inaccessible catalogue routes would add paperwork without corpus evidence.

### Rule
After this checkpoint, do **not** create additional acquisition-only documents unless a pass produces at least one of:
- a new byte-access route;
- a directly readable T0 page;
- a manifest/canvas identifier;
- a verified Christaller bitstream;
- or a materially new primary/near-primary witness.

Otherwise effort should shift to a different executable E9 dependency rather than inflate the acquisition record.
