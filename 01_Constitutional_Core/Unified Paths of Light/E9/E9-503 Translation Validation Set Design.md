# Unified Paths of Light — E9

## E9-503 — Translation Validation Set Design

Because full T1 remains inaccessible, E9 now freezes a validation-set design before activating any T3/T4 translation workflow.

### Validation strata
Construct a minimum validation set containing:
- straightforward short proverbs;
- figurative/metaphorical proverbs;
- culturally specific vocabulary;
- kinship/status language;
- legal/adjudicative language;
- resource/property language;
- harm/safety language;
- ambiguous or polysemous cases;
- items with substantial Rattray commentary;
- known OCR-damaged Twi.

### Gold/reference layers
Prefer cases with two or more independent translation witnesses:
- Rattray T2;
- Lange T1 or T1-derived permissioned excerpt;
- Akrofi/T3;
- other identified scholarly quotation.

### Purpose
The validation set must test whether a fallback translation preserves the distinctions that matter for ethical extraction, not merely whether it produces fluent English.
