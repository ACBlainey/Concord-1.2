# Unified Paths of Light — E9

## E9-228 — Occurrence Pattern Note: Proportionality, Scale and Resource Use

R350 and R354 reinforce the E9 proportionality topology.

- R350: a child's hand is easily filled.
- R354: the child cuts only the amount of yam that will fit the child's mouth.

The shared functional structure is that **appropriate quantity depends upon the recipient's actual capacity**.

This differs from simple scarcity. The issue is fit between resource quantity and usable capacity. Excess provision or taking is not automatically beneficial merely because more is available.

No compression is performed.
