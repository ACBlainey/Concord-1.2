# Unified Paths of Light — E9

## E9-1202 — Parent-Child Compression Register 026: AR546–AR562

### Existing parents extended

**PC-P081 — mechanism/intervention fit**
- AR546 — use the proper mechanism when it is available.
- AR547 — scarcity can justify a functional substitute when the preferred mechanism/resource is unavailable.

These are complementary children: preferred fit versus scarcity-conditioned substitution.

**PC-P051 — exposure and hazard**
- AR549 — participation can create opportunity for hazard.

**PC-P049 / PC-P094 — recovery and repair**
- AR550 — recovery should not pursue restoration of an object that no longer serves the objective.
This adds an endpoint/continued-value test to repair.

**PC-P056 — condition-creating responsibility**
- AR551 — responsibility can attach to agents who create hazardous or obstructive conditions.

**PC-P057 — norm continuity and genuine change**
- AR552 — declared normative change should be tested against continuing constitutive practice.

**PC-P001 — calibrated self-assessment**
- AR553 — inflated self-assessment impairs accurate orientation.
- M008/AR554 is already represented under capability-attribution failure.

**PC-P084 — entitlement**
- AR555 — another related agent's possession does not itself create entitlement.

**PC-P039 — coordinated plurality**
- M009/AR556 — some functions structurally require coordinated plurality.

**PC-P008 / reference-point evaluation**
- M010/AR557 — the same event can produce opposed consequences for different populations/agents.

**PC-P042 — irreversible communication**
- AR558 — anticipated irreversibility of released communication supports prospective restraint.

**PC-P045 — embedded/system dependency**
- AR559 — effects on a containing system can propagate to its contents.

**PC-P017 — revisable judgment**
- AR560 — judgment should remain revisable as evidence accumulates.

**PC-P024 / developmental timing**
- AR561 — slow progress does not itself establish failure.

**PC-P079 — agent-specific embodied need**
- AR562 — another agent's experience cannot satisfy one's own need.
