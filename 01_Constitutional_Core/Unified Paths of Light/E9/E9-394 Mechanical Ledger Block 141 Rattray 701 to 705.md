# Unified Paths of Light — E9

## E9-394 — Mechanical Ledger Block 141: Rattray 701–705

701 / C3065 = Y — rain that falls unnoticed at night leaves visible ground evidence by dawn. Failure to observe an event directly does not establish that it did not occur; consequences can provide later evidence.

702 / C115 = Y — the Rattray number is absent in the OCR. One should not walk through an already failing maize crop carrying a “bad charm” and thereby attract blame for failure that was already likely. Agents should avoid creating misleading causal appearances that can cause pre-existing failure to be falsely attributed to them.

703 / C117 = Y — the Rattray number is absent in the OCR. A charm intended to comfort but secured with a mourning knot has not really benefited the recipient. An intervention should be evaluated by its total effect; a nominal benefit can be nullified by an accompanying harmful component.

704 / C118 = Y — what is bad luck for one person is good luck for another. The same event can have opposing effects on different agents; evaluation must identify whose outcome is being assessed.

705 / C119 = Y — a knave for one person is a good person for another. Social/moral evaluation can vary with relationship and experience; one party's judgment of an agent is not automatically sufficient evidence for another party's evaluation.

### AR467 — R701/C3065
Lack of direct observation does not establish non-occurrence when later consequences provide evidence of the event.

### AR468 — R702/C115
Agents should avoid creating misleading causal appearances that can cause a pre-existing failure to be falsely attributed to them.

### AR469 — R703/C117
An intervention should be evaluated by its total effect; a nominal benefit can be nullified by an accompanying harmful component.

### AR470 — R704/C118
The same event can have opposing consequences for different agents; evaluation must specify the affected perspective.

### AR471 — R705/C119
One party's evaluation of an agent does not automatically establish how that agent functions in another relationship.
