# Unified Paths of Light — E9

## E9-1227 — Parent Inventory Consolidation Register 019: System Maintenance, Adaptation and Repair

### Higher internally derived parents

**HC-P045 — Functional systems require maintenance before degradation becomes terminal**

Subsumes:
- maintenance portions of PC-P029;
- AR237/427/428/454;
- PC-P046 where neglected enabling infrastructure becomes a failure point.

Core structure:
> Sustained function requires timely maintenance of enabling conditions; delay reduces adaptive margin and can convert manageable degradation into failure.

**HC-P046 — Adaptation should preserve function while responding to changed conditions**

Subsumes:
- PC-P011 — context-sensitive participation;
- PC-P057 — norm continuity/genuine change;
- PC-P081 mechanism-fit/substitution portions;
- AR495/546/547.

Core structure:
> Changed conditions can require altered behaviour, mechanisms or conventions, but adaptation should remain connected to the function or constraint that justified the prior form.

**HC-P047 — Recoverability should determine repair, replacement or abandonment**

Subsumes:
- HC-P037 / PC-P049 / PC-P094;
- M011;
- AR413/493/550.

Core structure:
> Intervention after degradation should distinguish what remains recoverable from what no longer serves the relevant objective, using that distinction to choose repair, reuse, replacement or abandonment.

### Architectural note

HC-P047 is the general systems-level expression of the same structure previously observed in resource repair. HC-P037 is therefore marked **SUBSUME under HC-P047** while remaining as a domain implementation for provenance.
