# Unified Paths of Light — E9

## E9-1117 — Normalisation Ledger N122: AR546–AR551

| AR | Source | Normalised ethical proposition | First-pass relation note |
|---|---|---|---|
| AR546 | R796 / C1937 | When the mechanism designed for a function is available, an inferior or indirect interface should not replace it without reason. | Fit-for-function mechanism. |
| AR547 | R798 / C2077 | Under resource scarcity, functional substitutes can preserve an objective when the preferred resource is unavailable. | Scarcity substitution. |
| AR548 | R799 / C2150 | Burdens imposed by adjudication should attach according to the judgment rather than be transferred to the successful claimant. | Adjudicative burden allocation. |
| AR549 | R801 / C2186 | Hazard exposure depends partly on participation in conditions that create opportunity for that hazard. | Exposure-conditioned risk. |
| AR550 | R803 / C2226 | Recovery effort need not be spent on an object or option that has genuinely ceased to serve the agent's objective. | Objective-sensitive recovery. |
| AR551 | R804 / C2236 | Responsibility analysis should include agents who create hazardous or obstructive conditions, not only those who later encounter them. | Condition-creating responsibility. |

AR546–AR547 are complementary rather than contradictory: use the proper mechanism when available, but substitute functionally when scarcity removes the preferred option.
