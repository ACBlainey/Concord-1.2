# Unified Paths of Light — E9

## E9-437 — Occurrence Pattern Note: System Dependency, Succession and Delayed Failure

R766 and R768–770 form a strong systems cluster.

R766: one tree does not make a forest — some system properties require plurality.

R768: when a great tree falls, a smaller papaw can occupy its place — system roles can be succeeded by differently scaled components.

R769: young shoots can briefly emerge from the fallen tree yet later die when the sustaining sap disappears — loss of support can produce delayed rather than immediate failure.

R770: a tree standing in a small village has roots in the houses — system dependencies can extend beyond visible boundaries.

Together these describe:
- plurality;
- succession;
- hidden dependency;
- delayed collapse;
- boundary-crossing integration.

This is unusually close to a general systems vocabulary while remaining mechanically grounded in four separate source items.
