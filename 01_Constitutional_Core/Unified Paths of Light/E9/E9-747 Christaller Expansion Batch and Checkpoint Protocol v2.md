# Unified Paths of Light — E9

## E9-747 — Christaller Expansion Batch and Checkpoint Protocol v2

The existing 20-item mechanical unit is retained.

### Every T0 batch
- inspect 20 printed Christaller items in order;
- transcribe exact IDs and Twi/source text;
- mark variants;
- test E9-RX-1.0 membership;
- test NC-ID candidates only when source correspondence warrants it;
- assign translation-debt status where appropriate;
- do not perform ethical classification behind a closed translation gate.

### Every 100 newly eligible C-only candidates
Checkpoint:
1. T0 coverage;
2. R-overlap count;
3. C-only candidate count;
4. NC-ID matches;
5. T0 holds;
6. translation coverage/debt;
7. only after translation activation: Y/Z/H/X and novelty/saturation metrics.

The first 500 C-only items remain mandatory before saturation can justify stopping.
