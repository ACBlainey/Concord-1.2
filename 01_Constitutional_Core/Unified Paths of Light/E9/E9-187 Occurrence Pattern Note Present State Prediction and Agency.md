# Unified Paths of Light — E9

## E9-187 — Occurrence Pattern Note: Present State, Prediction and Agency

R272 and R274 create a useful distinction concerning state and agency.

R272 refuses to call a sheep dead while it is still alive, even when death is approaching. Prediction is not present fact.

R274 states that the dead sheep does not choose the knife. Once the state transition has actually occurred, an important capability — choice — is absent.

Together the occurrences distinguish:
1. anticipated state from actual state;
2. actual state from the capabilities available within that state.

This is retained at occurrence level without importing an external theory of consent or personhood.
