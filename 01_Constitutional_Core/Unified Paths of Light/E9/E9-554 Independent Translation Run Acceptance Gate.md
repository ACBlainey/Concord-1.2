# Unified Paths of Light — E9

## E9-554 — Independent Translation Run Acceptance Gate

Before scoring an incoming candidate run, verify:

- exactly 50 frozen R-IDs returned;
- no substitutions;
- no missing rows;
- candidate English fixed;
- uncertainties fixed;
- provenance complete;
- translator attests that answer-key English was not supplied.

### If incomplete
Do not patch candidate translations in the scoring context.

Return the missing rows to the same isolated translation process or mark the run incomplete.

### If contaminated
Preserve the run for provenance but exclude it from the blinded validation statistic.

This prevents a technically complete but non-independent run from passing the T4 gate.
