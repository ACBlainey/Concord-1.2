# Unified Paths of Light — E9

## E9-1196 — Parent-Child Compression Register 021: AR441–AR461

### Existing parents extended

**PC-P051 — hazard and protective buffering**
- AR441 — agents nearest an uncontrolled hazard can bear disproportionate exposure.
- AR442 — dangerous component proximity can create interface risk.
- AR449 — protective support must remain accessible during crisis.
- AR450 — a shared environment can still produce unequal exposure because protection/position differs.
- AR456 — contraction of a protective environment can increase vulnerability.

**PC-P085 — consistency and non-self-exemption**
- AR444 — the same safety rationale should be applied consistently across uses.

**PC-P060 — non-event evidence limits**
- AR445 — absence of conspicuous warning does not establish safety.

**PC-P005 — causal inquiry**
- AR446 — anomaly can license investigation.
- AR448 — observable change should be treated as potentially causally grounded.

**PC-P008 — reference-dependent adequacy**
- AR451 — irrelevant qualities need not be present for a function.
- AR457 — inadequacy for one function does not establish inadequacy for another.
- AR452 — a resource can change valence across functions.
- AR472 later adds recipient prior-access dependence.

**PC-P089 — vulnerability and inducibility**
- AR453 — unmet need increases susceptibility to inducement.

**PC-P029 — stewardship**
- AR454 — storage without active management can degrade quality.

**PC-P024 / PC-P080 — timing and endpoint**
- AR455 — transitional difficulty can be tolerable where it enables a superior endpoint.

**PC-P001 — environmental support and apparent capability**
- AR458 — favourable conditions can enable apparent power/confidence and should be distinguished from intrinsic capability.

### New provisional parent

**PC-P097 — Incompatible-outcome accountability**
- AR461 — blame can become structurally impossible to escape when mutually incompatible outcomes are each condemned.

PC-P097 is a sibling of M006's evaluative double bind, but one concerns social approval and the other accountability/blame.
