# Unified Paths of Light — E9

## E9-557 — Post-Translation Reference Join Procedure

Once a valid isolated run is fixed:

1. verify E9-554 acceptance;
2. freeze candidate file hash/version;
3. reveal Rattray English;
4. attach Rattray notes only where relevant;
5. add T1/T3 independent translation where available;
6. score P/A/N/R/C/E/M/U;
7. classify disagreements D1–D5;
8. assign translation debt;
9. calculate materially clean proportion.

### No retroactive translation repair
A candidate may not be edited after answer-key reveal.

A corrected translation is a new run, not a revision of the scored candidate.
