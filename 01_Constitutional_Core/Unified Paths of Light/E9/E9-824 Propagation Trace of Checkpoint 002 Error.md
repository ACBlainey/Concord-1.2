# Unified Paths of Light — E9

## E9-824 — Propagation Trace of Checkpoint-002 Error

The E9-60 aggregate error was inherited unchanged by later cumulative checkpoints.

Examples:
- E9-70 used 'previous verified 2–34: Y7 / Z15 / H11' and therefore produced Y15 / H15 instead of Y14 / H16;
- E9-75 inherited the same +1Y/−1H offset;
- E9-80 reported Y27 / H31 / AR26 instead of Y26 / H32 / AR26;
- E9-90 reported Y36 / H35 / AR35 instead of Y35 / H36 / AR35;
- E9-95 reported Y43 / H40 / AR42 instead of Y42 / H41 / AR42.

The offset then propagated through the remaining mechanical reconstruction and into final closure. It is a **single inherited bookkeeping error**, not a missing AR occurrence.
