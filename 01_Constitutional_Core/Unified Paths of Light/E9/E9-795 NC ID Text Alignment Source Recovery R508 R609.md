# Unified Paths of Light — E9

## E9-795 — NC-ID Text-Alignment Source Recovery: R508, R609

Primary local source recovery gives:

| R | source-language row recovered | printed C-ID |
|---:|---|---|
|508|`Wo yere a onye no, na ete se obi aguaman.`|none|
|609|`Atokoro see nokwapem.`|none|

R609 is independently attested in later Akan scholarship in essentially the same proverb form, but that later attestation does not supply a Christaller 1879 identifier. It is therefore contextual corroboration only, not T0 alignment.
