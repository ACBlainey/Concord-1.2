# Unified Paths of Light — E9

## E9-485 — Christaller Expansion Identifier Alignment Schema

Every Christaller expansion record will use the following minimum fields:

1. **C-ID** — printed Christaller identifier.
2. **T0 locator** — printed page and witness image/page locator.
3. **T0 source text** — exact or conservatively transcribed Twi.
4. **Variant field** — printed variant relation if present.
5. **Rattray overlap** — yes/no.
6. **Rattray number** — where overlap exists.
7. **Translation witness** — T1/T2/T3/T4.
8. **Translation text/status** — visible, partial, unavailable or disputed.
9. **Translation debt** — none/low/material/high.
10. **Yield state** — Y/Z/H/X only after translation gate permits.
11. **AR relation** — existing/new/none.
12. **Mediation note** — where required.

### Purpose
This schema makes source identity, overlap and translation provenance mechanically separable from ethical interpretation.

It also prevents the Christaller phase from repeating the earlier Rattray verification failures.
