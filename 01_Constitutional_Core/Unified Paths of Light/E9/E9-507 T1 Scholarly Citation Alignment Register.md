# Unified Paths of Light — E9

## E9-507 — T1 Scholarly Citation Alignment Register

Scholarly sources can supply high-confidence numbered Lange examples.

One accessible example explicitly explains the convention:
**CN2554** means Christaller Number 2554 in the Christaller collection as later arranged with Lange translations.

### Register purpose
Build a small set of entries where all of the following are visible:
- C-ID;
- English translation;
- attribution to Christaller/Lange;
- source citation.

These entries can serve as:
- spot checks on T0 alignment;
- validation anchors for Rattray/T3/T4;
- evidence that numbering conventions survive into modern scholarship.

### Caution
A scholarly author may quote only part of a proverb or modernise punctuation. The register must distinguish verbatim translation from paraphrase.
