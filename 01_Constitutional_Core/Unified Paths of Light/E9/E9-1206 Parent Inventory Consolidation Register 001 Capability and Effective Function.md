# Unified Paths of Light — E9

## E9-1206 — Parent Inventory Consolidation Register 001: Capability and Effective Function

### Scope

First consolidation pass over the capability/effective-function portion of the PC-P inventory.

### Higher internally derived parents

**HC-P001 — Capability claims require function-relevant grounding**

Subsumes:
- PC-P001 — performance-grounded capability assessment;
- relevant capability-assessment portions of PC-P012;
- PC-P017 where independent evaluation concerns competence claims;
- PC-P055 where apparent resilience/capability must be distinguished from secure capability.

Core structure:
> Capability should be inferred from function-relevant evidence, demonstrated performance and appropriate comparison rather than assertion, appearance, status or a single irrelevant dimension.

Distinct children remain recoverable: performance, multidimensionality, domain specificity, environmental support, independent evaluation, hidden capability and comparative calibration.

**HC-P002 — Realised capability depends on enabling conditions**

Subsumes:
- PC-P010 — capability-sensitive support;
- PC-P046 — critical enabling infrastructure;
- PC-P045 where prerequisite failure blocks downstream function;
- PC-P039 where coordinated plurality is structurally required.

Core structure:
> What an agent or system can actually realise depends not only on intrinsic capacity but also on support, prerequisites, infrastructure and complementary participants.

**HC-P003 — Sufficiency and value are function-relative**

Subsumes:
- PC-P008 — reference-dependent sufficiency/value;
- PC-P081 — intervention-condition fit;
- portions of PC-P059 concerning capacity/surplus relative to function.

Core structure:
> Adequacy, value and fit must be evaluated relative to the relevant function, recipient, condition and available alternatives.

**HC-P004 — Capability develops and can be corrected**

Subsumes:
- PC-P002 — experience-mediated correction/guidance;
- PC-P034 — non-instructed/practice-based development;
- PC-P030 — incremental construction;
- developmental portions of PC-P024 and PC-P098.

Core structure:
> Capability is developmentally variable and can emerge, improve or be corrected through experience, practice, support, sequencing and time.

### Retained sibling mechanisms

- PC-P047 productive causal-role attribution — **RETAIN**, because credit/production is not reducible to capability.
- PC-P074 specialist capability as continuity infrastructure — **BRIDGE** to systems/continuity.
- PC-P077 bottlenecks/transition hazards — **BRIDGE** to systems and hazard.
- PC-P101 exploration as information generation — **BRIDGE** to epistemic structure.

### Result

The capability region compresses from numerous working parents into **four higher parents plus retained bridges**, without forcing a single generic “capability” root.

No external comparison has been used.
