# Unified Paths of Light — E9

## E9-1234 — Higher-Parent Compound Audit 001: Operator Candidates

### Candidate operator set

The following HC structures recur across multiple substantive domains and are provisionally classified as **operators or conditions**, not candidate roots:

**O-C01 — Reality/evidence responsiveness**
- HC-P005

**O-C02 — Bounded inference**
- HC-P006

**O-C03 — Verification**
- HC-P008

**O-C04 — Correctability/revisability**
- HC-P009

**O-C05 — Reference-point specification**
- HC-P048

**O-C06 — Context-sensitive implementation**
- HC-P049

**O-C07 — Timing sensitivity**
- HC-P051

**O-C08 — Dependency/prerequisite sequencing**
- HC-P052

**O-C09 — Irreversibility sensitivity**
- HC-P053

### Why these are not yet roots

Each changes how another substantive concern is evaluated or implemented:
- evidence changes confidence;
- inference limits claims;
- verification tests claims;
- correction revises judgments;
- reference point changes evaluation;
- context changes implementation;
- timing changes effectiveness;
- sequencing constrains order;
- irreversibility changes the action threshold.

### Not classified as pure operators

- HC-P007 truthful representation has substantive interpersonal/collective normative content.
- HC-P010 intelligible communication concerns an actual communicative obligation.
- HC-P011 information boundaries protect legitimate interests and agency.
- HC-P012 information-system integrity is structural as well as epistemic.
- HC-P024 proportional response may be operator-like but is currently anchored strongly in harm/repair.

### Status

All classifications are **provisional** pending architecture separation and minimum-stability testing.
