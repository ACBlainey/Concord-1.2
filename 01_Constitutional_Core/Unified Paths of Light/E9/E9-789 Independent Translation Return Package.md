# Unified Paths of Light — E9

## E9-789 — Independent Translation Return Package

A completed independent run must return:

1. run identifier and class A/B/C;
2. contamination declaration;
3. all 50 source rows as received;
4. all 50 frozen candidate translations;
5. uncertainty notes;
6. declared lexical resources;
7. candidate-freeze evidence/version;
8. no answer-key material in the pre-unblind package.

The scoring stage then appends answer-key comparison and material-error coding as a separate layer. This separation preserves auditability.
