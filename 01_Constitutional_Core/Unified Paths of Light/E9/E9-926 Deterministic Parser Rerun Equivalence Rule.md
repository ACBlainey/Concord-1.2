### Frozen equivalence rule

A rerun set B₁ is admissible as the operational successor to B₀ only if it is generated from the same local `ashanti.txt` witness and:

1. reads the Rattray corpus in source order;
2. admits only explicit numeric parenthetical Christaller identifiers or the conservative OCR normalisations already frozen in E9-876;
3. does not manufacture identifiers for the eleven structural no-ID/non-Christaller rows;
4. preserves R369 as a one-to-many relation;
5. supplements only relations independently reconciled before the rerun;
6. yields exactly **805 relation edges**;
7. yields exactly **800 unique C-IDs**;
8. reproduces exactly the five known duplicate groups: C228, C1335, C2610, C2613 and C3127.

Failure of any invariant means B₁ is not demonstrated equivalent to Pass 001 and must remain a separate diagnostic set.

### Anti-targeting rule

The parser must not be tuned by asking which changes produce 805. Parsing rules are frozen first; counts are inspected afterward.
