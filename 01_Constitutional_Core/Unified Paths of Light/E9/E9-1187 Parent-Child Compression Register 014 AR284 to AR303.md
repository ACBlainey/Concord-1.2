# Unified Paths of Light — E9

## E9-1187 — Parent-Child Compression Register 014: AR284–AR303

### Existing parents extended

**PC-P003 / PC-P054 — relational reciprocity and capability-sensitive support**
- AR284 — kinship/network relations provide support with graded proximity.
- AR293 — care/preference can vary with relational proximity.
- AR296 — low status does not erase dignity obligations arising from close relationship.
- AR297 — material disadvantage does not dissolve a durable relation or justify advantageous replacement.
- AR300 — defect/disappointment does not erase the relational bond.

**PC-P012 / PC-P067 — classification and evaluation**
- AR286 — one community's evaluation need not represent another's.
- AR289/M006 — social evaluation can condemn opposed positions, creating a double bind.
- AR295 — status/relational bias can discount another's achievement.

**PC-P044 — collective information resilience**
- AR292 — false hostile reports can manufacture intergroup conflict.

**PC-P031 — entitlement/ownership boundary**
- AR294 — weak ownership boundaries in close relations can teach wrongful taking.

**PC-P034 — development without explicit instruction**
- AR301 — behaviour can be learned through repeated proximity/observation without explicit teaching.
- AR302 — guidance to one learner can spill over to others.

### New provisional parents

**PC-P068 — Relational durability under stress**
- AR285 — some relationships are durably continuous.
- AR297 — material disadvantage need not dissolve them.
- AR300 — defect/disappointment need not dissolve them.

**PC-P069 — Collective failure can emerge from local conditions**
- AR287 — distributed local failures can aggregate into collective failure.
- AR288 — large scale does not eliminate vulnerability.

**PC-P070 — Consensus pressure can constrain agency**
- AR291 — collective consensus can coercively pressure individual conduct.

**PC-P071 — Functional self-maintenance for obligation**
- AR298 — agents should preserve minimum bodily capacity needed to fulfil demanding obligations.

**PC-P072 — Network-node dependency**
- AR299 — loss of a central relational node can reduce network support.

**PC-P073 — Predictable access supports restraint**
- **M004 (AR108+AR303)** — reliably approaching access/return can make immediate pursuit unnecessary.

PC-P073 is a specialised timing/agency parent and remains linked to PC-P024.
