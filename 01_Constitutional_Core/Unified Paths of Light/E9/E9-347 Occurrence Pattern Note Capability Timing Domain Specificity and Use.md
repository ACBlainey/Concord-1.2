# Unified Paths of Light — E9

## E9-347 — Occurrence Pattern Note: Capability Timing, Domain Specificity and Use

R589, R592, R593, R596 and R600 create a dense capability/knowledge cluster.

R589: knowledge must sometimes be translated or explained for the receiver.

R592: learning after the opportunity has disappeared can make newly acquired capability practically ineffective.

R593: low general competence can coexist with genuine domain-specific knowledge.

R596: wisdom is not represented as something whose proper function is simply storage.

R600: deliberately putting wisdom away is incompatible with asking for understanding while leaving that capability unused.

Together these distinguish:
1. possession of knowledge;
2. comprehensibility to the recipient;
3. domain specificity;
4. timing of acquisition;
5. actual deployment.

The source therefore repeatedly treats effective knowledge as relational and operational rather than as a binary property that an agent simply “has” or “does not have.”
