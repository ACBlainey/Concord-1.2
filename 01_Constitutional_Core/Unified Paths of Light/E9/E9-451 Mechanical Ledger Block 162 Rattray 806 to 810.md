# Unified Paths of Light — E9

## E9-451 — Mechanical Ledger Block 162: Rattray 806–810

806 / C2302 = Y — when the eyes rise above the eyebrows, glossed by Rattray as pride/conceit, one gets lost. Inflated self-assessment can impair orientation and judgment.

807 / C2337 = Y — when one does not know how to dance, one blames the drum's sound. An agent may externalise a capability deficit by blaming the environment or tool rather than recognising the limitation in their own performance.

808 / C2504 = Y — one's sister may possess an attractive quality, but that does not make the associated benefit one's own. A valued quality or resource possessed by a related person does not automatically transfer entitlement to oneself.

809 / C2793 = Y — one finger cannot pick an object up from the ground. Some tasks require coordinated plurality; an isolated component can be individually functional yet insufficient for the task.

810 / C2854 = Y — the same matter can be laughed about in one place and cried about in another. Evaluation of an event must specify the affected context or population; the same event can produce opposed consequences for different groups.
