## E9-929 — Machine-Readable Artifact Preservation Requirement

The Pass-001 serialization gap demonstrates that aggregate checkpoints are insufficient for exact set-difference closure.

### New preservation requirement

For the remainder of E9, every mechanical set used in a cardinality or exclusion calculation must preserve its literal membership, not only its count.

At minimum the closure package must retain:

- authoritative 820-edge set A;
- deterministic parser set B₁;
- keyed difference A−B₁;
- unique C-ID projection of A;
- duplicate-group register with contributing R rows;
- eleven-row structural exclusion register.

Each edge record must retain both R-ID and C-ID. A bare list of C-IDs is insufficient because duplicate and one-to-many relations would lose provenance.

### Methodological consequence

This is a prospective correction to the E9 mechanical workflow. Earlier aggregate checkpoints remain valid as recorded observations, but future exact-set claims require serialized member-level evidence.
