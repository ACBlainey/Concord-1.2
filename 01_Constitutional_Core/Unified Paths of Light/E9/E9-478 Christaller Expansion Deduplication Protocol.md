# Unified Paths of Light — E9

## E9-478 — Christaller Expansion Deduplication Protocol

Rattray items already carry Christaller identifiers. These identifiers provide the first deduplication layer for expansion into the larger Christaller corpus.

### Protocol
For every Christaller candidate:
1. check whether its Christaller identifier occurs in the closed Rattray ledger;
2. if yes, mark **R-overlap** and do not count it as a new corpus occurrence merely because it appears in a new witness;
3. if no, mark **C-only candidate**;
4. preserve textual variants where wording differs materially;
5. do not assume same identifier means identical OCR/translation wording without checking;
6. do not assume nearby Christaller numbers are semantically related.

### Variant handling
A materially distinct variant may be recorded as a variant relation, but must not inflate occurrence counts unless the frozen extraction protocol warrants a separate ethical occurrence.

### Purpose
This prevents the Christaller expansion from artificially increasing ethical density by recounting the same proverbs already processed through Rattray.
