# Unified Paths of Light — E9

## E9-1229 — Parent Inventory Consolidation Register 021: Timing, Sequencing and Irreversibility

### Higher internally derived parents

**HC-P051 — Timing can change the value or effectiveness of action**

Subsumes:
- PC-P024 — timing-sensitive obligation;
- PC-P073 — predictable access supports restraint;
- PC-P080 — delay can preserve harm;
- AR339/370/427/455/490/491/506/561.

Core structure:
> The same action can change in value or effectiveness depending on when it occurs; delay, premature action, predictable access and closing opportunity windows are ethically relevant conditions.

**HC-P052 — Dependency order constrains viable sequencing**

Subsumes:
- PC-P098 — procedural/developmental prerequisite sequencing;
- AR480/520/529;
- prerequisite portions of PC-P045.

Core structure:
> Where one function depends on another, viable action should respect the order in which enabling conditions must be established.

**HC-P053 — Irreversibility raises the threshold for action**

Subsumes:
- PC-P036 irreversible-loss portions;
- AR513/558 irreversible communication;
- relevant one-way loss structures.

Core structure:
> Where action removes future options or cannot realistically be recalled, anticipated irreversibility gives additional reason for restraint, verification or preservation of alternatives.

### Operator signal

HC-P051–HC-P053 are strongly cross-domain. They operate on communication, development, resource use, hazard response, continuity and agency. They are therefore candidates for an eventual **condition/operator layer** rather than substantive roots.
