# Unified Paths of Light — E9

## E9-509 — Translation Validation Pilot Gate

The prerequisites for a translation-method pilot are now defined.

### Pilot input
50 Rattray-overlap items selected across the frozen semantic strata.

### Procedure
For each:
1. take Twi/source text without exposing the historical English translation to the translation step;
2. generate the candidate fallback rendering;
3. compare afterward against Rattray;
4. triangulate disagreements with Lange/T3 where accessible;
5. score using E9-504;
6. record translation debt.

### Output
The pilot must report:
- material-error count;
- error types;
- ambiguity count;
- cases where fallback was arguably superior or more literal;
- cases requiring external linguistic review;
- pass/fail against the pre-frozen threshold.

### Gate
No bulk C-only ethical extraction begins before this pilot is completed or direct full T1 access is obtained.
