# Unified Paths of Light — E9

## E9-818 — Independent-Run Provenance Minimum

To admit a returned 50-item run, record at minimum:

`run-id | execution context/tool | date | run class | source-package version | prompt version | answer-key exposure declaration | lexical aids | candidate-freeze identifier | operator note`

No personal identity is required from a human reviewer unless voluntarily supplied. What matters experimentally is separation from the answer key and reproducibility of the translation conditions.
