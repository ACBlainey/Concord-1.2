# Unified Paths of Light — E9

## E9-214 — Mechanical Ledger Block 069: Rattray 341–345

341 / C7 = H — the child may resemble the father but belongs to the mother's matrilineal group. This is clear kinship-system evidence, but a transferable ethical function is not independently established.

342 / C8 = Y — the rhetorical question asks whether a child should receive the breast only after crying. Care for a dependent's need should not require the dependent first to signal distress.

343 / C10 = Y — when a child's excrement soils the caregiver's lap, it is wiped away rather than cutting off the affected flesh. Remediation should be proportionate to the problem and avoid destructive overreaction.

344 / C11 = Y — when one's child dances badly, the parent should tell the child it is not good rather than indulgently affirming poor performance. Caregiving includes truthful corrective feedback rather than unconditional validation of deficient performance.

345 / C12 = Y — cheating is wrong whether one's own child cheats the co-wife's child or the reverse. The standard applied to harmful conduct should not change according to which closely related party benefits.

### AR197 — R342/C8
Care for a dependent's foreseeable need should not necessarily be withheld until the dependent first expresses distress.

### AR198 — R343/C10
Corrective action should be proportionate to the problem and should not destroy what can instead be cleaned or repaired.

### AR199 — R344/C11
Developmental care can require truthful corrective feedback rather than indulgent affirmation of poor performance.

### AR200 — R345/C12
A standard against harmful or dishonest conduct should be applied consistently regardless of which favoured related party benefits.
