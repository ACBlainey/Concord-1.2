# Unified Paths of Light — E9

## E9-552 — Independent Translation Run Provenance Requirements

Every candidate-translation run must record:

1. run identifier;
2. date;
3. translating system/person;
4. model/version if applicable;
5. exact source dataset version;
6. exact prompt version;
7. whether internet/dictionaries were available;
8. any external lexical resources actually used;
9. confirmation that Rattray English was not supplied;
10. confirmation that prior E9 ethical outputs were not supplied.

### Invalidating contamination
A run is not blind if the translator is intentionally supplied the historical English or E9's prior item-level semantic conclusions.

### Reproducibility
If multiple isolated translators are later used, each run remains separate. Their outputs are not averaged before individual scoring.
