# Unified Paths of Light — E9

## E9-567 — Overlap Index Quality-Control Sampling Plan

The Rattray-to-Christaller index will be quality-checked across the full selected corpus.

### Checkpoints
At minimum inspect:
- opening items;
- approximately each hundred-item region;
- known OCR-damaged regions;
- final items;
- anomalous identifiers.

### Validation
For sampled entries compare:
- R-ID;
- printed parenthetical C-ID;
- Twi line;
- neighbouring sequence.

### Failure handling
If a systematic OCR pattern is found, pause bulk arithmetic and quantify the affected region before proceeding.

### Goal
The overlap set must be reliable enough that a C-only item is not falsely created merely because Rattray's C-ID was misread.
