# Unified Paths of Light — E9

## E9-784 — Independent Translation Output Schema

Each of the 50 rows must return exactly:

`R-ID | source Twi as received | conservative English candidate | uncertainty note | lexical aid used? | lexical aid citation/name if any`

### Run classes
- **Class A:** source-only model, no external dictionary/web;
- **Class B:** declared lexical aid;
- **Class C:** linguistic reviewer.

The class must be declared before scoring. Historical Rattray/Lange translations of the test items are answer-key resources and cannot be declared as lexical aids.
