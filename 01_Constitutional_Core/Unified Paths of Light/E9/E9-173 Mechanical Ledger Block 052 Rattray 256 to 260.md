## E9-173 — Mechanical Ledger Block 052: Rattray 256–260

256 / C1768 = Y — even when hungry, the dog does not gnaw the bells around its own neck. Immediate appetite does not erase practical limits concerning resources or structures bound to one's own continuing function.

257 / C1766 = Y — when a dog picks up an egg, it breaks in its mouth. An agent's ordinary mode of handling can be incompatible with a fragile object, making capability context-dependent.

258 / C1767 = H — “a big thing does not get lost.” Salience/recoverability is suggested, but no ethical application is explicit enough for secure admission.

259 / C1772 = Y — a dog found on a high store rack that it could not have climbed must have been placed there by another. When an observed state exceeds an agent's capability to produce it, external agency should be considered.

260 / C1771 = Y — a dog already disposed to run will run still faster when a consequential family loss occurs. Existing disposition can be amplified by materially relevant incentive or urgency.

### AR138 — Rattray 256 / Christaller 1768
**Minimal function:** Immediate need or appetite need not justify consuming or damaging resources integral to one's own continuing role or condition.
**Confidence:** moderate-high.

**Confidence:** high.

### AR140 — Rattray 259 / Christaller 1772
**Minimal function:** When an observed outcome exceeds an agent's capacity to produce it unaided, causal analysis should consider assistance or intervention by another agent.
**Confidence:** high.

### AR141 — Rattray 260 / Christaller 1771

**Confidence:** moderate-high.
