# Unified Paths of Light — E9

## E9-518 — Translation Pilot Execution Plan

### Stage 1 — source-only dataset
Construct 50 rows containing:
- R-ID;
- C-ID;
- Twi/source text;
- source-quality flag.

Do not include Rattray English.

### Stage 2 — candidate translation
Translate all 50 rows conservatively.

Record uncertainty before seeing reference English.

### Stage 3 — reference reveal
Join the candidate sheet back to:
- Rattray English;
- commentary where relevant;
- any available T1/T3 validation witness.

### Stage 4 — score
Apply E9-515 and E9-516.

### Stage 5 — decision
Calculate:
- materially clean items / scorable items;
- material-error rate;
- uncertainty/debt rate;
- error-type distribution.

Compare with the pre-frozen ≥90% threshold.

### Stage 6
Only if passed may T4 become a controlled translation route for C-only material. Individual TD2/TD3 items remain gated.
