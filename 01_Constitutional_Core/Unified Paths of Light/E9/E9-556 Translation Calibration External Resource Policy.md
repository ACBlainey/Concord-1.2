# Unified Paths of Light — E9

## E9-556 — Translation Calibration External Resource Policy

An isolated translator may use lexical aids only if the run declares them prospectively.

### Run classes
**Class A — source-only model**
No external dictionary or web aid.

**Class B — declared lexical aid**
Dictionary/grammar resources permitted; every material consultation recorded.

**Class C — linguistic reviewer**
Human or specialist linguistic review.

### Comparison value
Class A tests raw fallback capability.
Class B more closely resembles the controlled T4 workflow intended for difficult Christaller-only material.

### Prohibition
Rattray/Lange translations of the test items are answer-key resources, not lexical aids, and cannot be consulted before candidate fixation.
