# Unified Paths of Light — E9

## E9-785 — Independent Translation Contamination Declaration

Before unblinding, the translator/run operator must declare:

1. whether the run context had access to Rattray English for any frozen item;
2. whether it had access to Lange translations for any frozen item;
3. whether search/retrieval surfaced historical translations during candidate generation;
4. what dictionaries, corpora or lexical tools were used;
5. whether any candidate was revised after seeing an answer-key translation.

Any material answer-key exposure before candidate freeze makes the affected run **contaminated** and excludes it from the ≥90% validation calculation.
