## E9-1167 — Duplicate and Near-Duplicate Audit Register 028: AR563–AR571

| Candidate set | Relation | Decision | Information-loss test |
|---|---|---|---|
| AR563 / AR198 | proportionate repair | **MERGE — HIGH CONFIDENCE** | Both privilege proportionate repair where the underlying useful object/system remains correctable rather than destruction or abandonment. |
| AR563 / AR493 | recoverability | RETAIN after M011 | AR493 is a restraint against destruction after initial failure; M011 positively specifies proportionate repair under correctable degradation. |
| AR564 / AR116 | response integrity | RETAIN | Preserving one's standards when responding to disorder differs from a critic sharing the condemned defect. |
| AR565 / AR173 | epistemic limits | RETAIN | Mental states require inference because they are not directly observable; opposed agents have limited observation/information. |
| AR566 / AR347 | proximity-sensitive hazard | **MERGE — HIGH CONFIDENCE** | Both state that hazard/risk materially increases or varies with proximity/accessibility to the harmful source. |
| AR566 / AR441 | proximity-conditioned exposure | RETAIN after M012 | AR441 additionally concerns disproportionate consequences borne by agents nearest an uncontrolled hazard. |
| AR567 / AR568 | derivative circumvention | **MERGE — VERY HIGH CONFIDENCE** | The propositions are substantively identical; AR568 merely adds “directly” to dependent derivatives. |
| AR569 / AR338 | necessity and preference/constraint | RETAIN | AR338 prioritises immediate basic need over deferred liability; AR569 states necessity can constrain preferences/avoidance because viable alternatives disappear. |
| AR570 / AR349 | anticipated hazard response | RETAIN | AR349 calls for protective adaptation where threat is anticipated; AR570 supports not deliberately entering a known avoidable severe hazard. |
| AR570 / AR518 | hazard reduction | RETAIN | Reducing an existing/foreseeable hazard differs from avoiding deliberate entry into it. |
| AR571 / AR210 | intergenerational continuity | **MERGE — HIGH CONFIDENCE** | Both state that information, norms or practices can persist across time through intergenerational transmission, sustaining continuity. |

### Canonical merges authorised

**M011 — AR198 + AR563:**  
*Where a useful object or system remains correctable, degradation should invite proportionate repair rather than destruction or abandonment.*

**M012 — AR347 + AR566:**  
*Hazard exposure or intensity can depend materially on proximity or accessibility to the harmful source.*

**M013 — AR567 + AR568:**  
*A prohibition should apply consistently to dependent derivatives where using the derivative would defeat the substance of the original restriction.*

**M014 — AR210 + AR571:**  
*Information, norms or practices can persist across time through intergenerational transmission, sustaining collective continuity.*

# **AUDIT REGISTER 028 COMPLETE — M011–M014 AUTHORISED**
