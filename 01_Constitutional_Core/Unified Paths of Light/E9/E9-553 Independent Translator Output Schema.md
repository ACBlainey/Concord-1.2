# Unified Paths of Light — E9

## E9-553 — Independent Translator Output Schema

The candidate output format is frozen:

| Field | Meaning |
|---|---|
| Run-ID | independent translation run |
| R-ID | Rattray item |
| C-ID | Christaller identifier |
| Candidate | conservative English translation |
| Lexical uncertainty | uncertain source terms |
| Structural uncertainty | syntax/agent/modality uncertainty |
| OCR concern | none/minor/material |
| Confidence | high/medium/low |
| External aid | none or named resource |

### Prohibited output
No ethical principle, moral lesson, AR label or X-root mapping is requested.

This keeps translation and ethical extraction as separate experimental stages.
