# Unified Paths of Light — E9

## E9-307 — Occurrence Pattern Note: Specialist Knowledge, Memory and Communication Infrastructure

R507's extended note is unusually rich even though the proverb itself is gender-hierarchical.

Rattray describes expert drummers who:
- train from childhood;
- learn royal genealogies, traditions and proverbs;
- reproduce culturally encoded verbal messages through drum patterns;
- perpetuate collective historical memory;
- transmit alarms;
- operate within message-specific secrecy constraints.

The important occurrence pattern is that **collective informational capability can reside in specialised trained agents and practices rather than in written infrastructure alone**.

This also shows that communication infrastructure can simultaneously serve:
1. emergency signalling;
2. historical continuity;
3. ceremonial transmission;
4. identity preservation.

No comparison to Concord continuity systems is made while the E9 firewall remains closed.
