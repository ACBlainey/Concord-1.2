# Unified Paths of Light — E9

## E9-459 — Occurrence Pattern Note: Context-Relative Effects Without Ethical Relativism

R810 states that the same matter may be laughed about in one place and cried about in another.

This continues a pattern already visible in:
- R684: the same resource can be useful in one function and dangerous in another;
- R704: the same event can have opposing consequences for different agents;
- R705: evaluation can differ across relationships;
- R689: resource sufficiency depends on function.

The recurring structure is not that every evaluation is equally valid.

Rather, **effects and relevance are indexed to context, function and affected agent**. A complete evaluation must specify:
- what happened;
- to whom;
- under what conditions;
- with what consequences.

This distinction is important because context sensitivity can coexist with disciplined evidence and consistent evaluative methods.
