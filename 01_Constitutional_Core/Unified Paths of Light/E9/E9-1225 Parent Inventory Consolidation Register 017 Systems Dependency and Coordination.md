# Unified Paths of Light — E9

## E9-1225 — Parent Inventory Consolidation Register 017: Systems, Dependency and Coordination

### Higher internally derived parents

**HC-P038 — System function depends on dependency structure, not isolated components**

Subsumes:
- PC-P045 — dependency-chain functionality;
- PC-P046 — critical enabling infrastructure;
- PC-P072 — network-node dependency where the node performs a system-support function;
- AR404/519/525/559 dependency propagation structures.

Core structure:
> System performance and failure depend on how components, prerequisites and support paths are connected; apparently minor or indirect elements can be functionally critical.

**HC-P039 — Some functions require coordinated plurality**

Subsumes:
- PC-P020 — collective effectiveness is not reducible to number;
- PC-P039 — coordination and complementary plurality;
- M009 — functions structurally requiring multiple coordinated components;
- AR211/212/213 complementary-role structures.

Core structure:
> Collective effectiveness can depend on differentiated, coordinated contribution rather than simple aggregation or the capacity of any single component.

**HC-P040 — Local conditions can aggregate into system-level outcomes**

Subsumes:
- PC-P069 — collective failure from local conditions;
- AR287/288 distributed vulnerability;
- AR386/394 burden propagation where local scarcity/deprivation transmits through dependencies.

Core structure:
> Repeated or connected local conditions can aggregate, propagate or amplify into collective outcomes that are not visible from any single component in isolation.

### Boundary

HC-P038 concerns architecture of dependency.  
HC-P039 concerns coordinated plurality.  
HC-P040 concerns emergence/propagation from local conditions.

They remain siblings.
