# Unified Paths of Light — E9

## E9-809 — Acquisition Versus Translation Dependency Note

The new Google Play route changes only the **T0 acquisition** branch. It does not solve the independent translation-validation dependency.

Conversely, a successful clean 50-item translation run would not solve Christaller page access.

The two gates remain logically independent:
- **Gate A:** direct T0 item access;
- **Gate B:** validated translation route.

C-only ethical extraction requires both adequate item access and adequate translation status.
