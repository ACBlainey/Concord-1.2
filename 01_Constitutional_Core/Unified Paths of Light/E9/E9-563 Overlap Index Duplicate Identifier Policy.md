# Unified Paths of Light — E9

## E9-563 — Overlap Index Duplicate-Identifier Policy

A Christaller identifier may not automatically be assumed unique within Rattray reconstruction.

### If the same C-ID appears more than once
Record each R-ID occurrence separately and classify the relation later as:
- repeated citation;
- variant;
- OCR collision;
- source duplication;
- unresolved.

### Set arithmetic
For expansion purposes:
- Rattray item count = numbered R-items;
- overlap-set size = number of unique valid reconciled C-IDs.

These quantities may differ.

### Consequence
The number of Christaller-only candidates cannot be calculated as 3600 minus 830 without first deduplicating and resolving identifier debt.
