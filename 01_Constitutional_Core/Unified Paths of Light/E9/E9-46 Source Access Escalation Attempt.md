# Unified Paths of Light — E9
## E9-46 — Source-Access Escalation Attempt

## Action
The source-access gate in E9-45 was actively re-tested rather than treated as terminal.

Open Library exposes a direct **Plain text** link for the 1916 Rattray edition and identifies the Internet Archive object as:

`ashantiproverbs00chrigoog`

The linked text object resolves to:

`ashantiproverbs00chrigoog_djvu.txt`

The Open Library record also exposes the PDF route.

## Result
The research interface reached the Open Library metadata and resolved the exact Internet Archive text target, but the archive payload failed at the redirected storage host.

This is an access-layer failure, not absence of a machine-readable source.

## Consequence
The precise machine-readable witness required by E9-43 is now identified.
