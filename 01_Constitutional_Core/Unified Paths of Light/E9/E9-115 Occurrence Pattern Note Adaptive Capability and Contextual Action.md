# Unified Paths of Light — E9

## E9-115 — Occurrence Pattern Note: Adaptive Capability and Contextual Action

Rattray 151–156 contains a concentrated set of occurrences concerning capability relative to context.

### Adapted care
R151 shows successful child-rearing despite absence of the expected biological mechanism.

### Function over appearance
R152 separates unconventional or laughable-looking performance from actual successful outcome.

### Self-created vulnerability
R153 shows protected capability being defeated when the agent itself exposes the vulnerable point.

### Protective withdrawal
R155 rejects shame as a sufficient reason not to retreat.

### Context-sensitive tempo
R156 preserves both haste and deliberation as potentially good.

Together these occurrences suggest that the corpus repeatedly evaluates conduct relative to circumstances, capability and outcome rather than through a single fixed behavioural form.

This remains an occurrence-level observation only. It is not a root and is not compared with the frozen X architecture.
