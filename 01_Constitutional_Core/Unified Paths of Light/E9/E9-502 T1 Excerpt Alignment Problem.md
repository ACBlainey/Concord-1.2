# Unified Paths of Light — E9

## E9-502 — T1 Excerpt Alignment Problem

The permissioned Weekly African Proverbs excerpts solve only part of the translation problem.

### What is visible
English translations from the Christaller/Lange volume occur in blocks.

### What is not yet visible
The web presentation does not expose a Christaller identifier beside each sentence.

### Why this matters
E9's frozen architecture requires C-ID as the primary key.

A translation that cannot be tied securely to a C-ID must not be inserted into the Christaller-only ledger merely because its wording appears distinctive.

### Permitted alignment routes
A permissioned excerpt may become usable if:
1. its Twi counterpart can be matched uniquely in T0;
2. a scholarly source supplies the C-ID for the same English wording;
3. another numbered bilingual witness provides an independently secure correspondence.

### Prohibited shortcut
Do not assign C-IDs by presumed sequence or thematic proximity.
