# Unified Paths of Light — E6
## E6-63 — N4 Pairwise Fusion and Semantic-Loss Test

Seven candidates remain: HR1–HR7.

## Fusion attacks

**HR1 + HR4 — protection/care:** rejected. Negative restraint and positive assistance differ in activation and burden.

**HR1 + HR3 — harm/agency:** rejected. Beneficial paternalism demonstrates semantic independence.

**HR1 + HR6 — harm/correction:** rejected. Prospective restraint and post-error corrigibility differ.

**HR2 + HR6 — truth/correctability:** rejected. Accurate belief can coexist with refusal to repair; correction can concern conduct rather than factual belief.

**HR2 + HR7 — knowledge/development:** rejected. Epistemic integrity does not entail capability-sensitive cultivation.

**HR3 + HR4 — agency/care:** rejected. Respectful non-interference does not satisfy serious positive need.

**HR3 + HR5 — agency/resources:** rejected. Resource continuity/entrustment survives cases without direct coercion.

**HR3 + HR7 — agency/development:** rejected. Preserving choice does not require cultivating capability.

**HR4 + HR5 — care/resources:** rejected. Stewardship includes acquisition/use/continuity beyond aid cases.

**HR4 + HR7 — care/development:** rejected. Immediate assistance and long-horizon capability formation are distinct.

**HR5 + HR6 — resources/correction:** rejected. Resource responsibility is not a special case of repair.

**HR6 + HR7 — correction/development:** rejected. Correcting error and proactively developing capability differ.

## Result
No pairwise fusion preserves all E6 functions without redefining a parent so broadly that it merely hides the distinction.
