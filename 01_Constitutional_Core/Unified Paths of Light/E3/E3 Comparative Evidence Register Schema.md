# Sacred Codes and Civilizational Longevity — E3
## Comparative Evidence Register — Schema and Counting Rules

**Status:** Controlling format for the final audited prevalence matrix.

---

## 1. Purpose

The source-provenance repair has established the main authority rules. The next stage requires a row-level register capable of supporting reproducible prevalence counts.

Each claimed tradition/principle match must therefore become an explicit evidence record.

## 2. Required Record

| Field | Meaning |
|---|---|
| E3-Q ID | Frozen Qur'an-derived principle |
| Tradition | One of the seven comparison families |
| Functional Grade | A direct; B strong functional; C corollary/partial; D no clear equivalent |
| SQ Grade | A direct canonical/foundational; B identifiable authoritative; C scholarly/generalised; D unsupported/mismatched |
| Exact Source | Named text/tradition/source |
| Passage / Location | Verse, chapter, Ang, sutta, analect, maxim, etc. |
| Functional Note | Why the source does or does not instantiate the E3 behaviour |
| Presence Decision | Secure / Provisional / Corollary / Absent-Unproven |
| Audit Note | Boundary, translation or scope caution |

## 3. Counting Rules

### Secure Presence
Functional **A or B** plus source quality **SQ-A or SQ-B**.

### Provisional Presence
Functional **A or B** but only **SQ-C** provenance.

### Corollary / Partial
Functional **C**, provided provenance is adequate.

### Absent / Unproven
Functional **D**, **SQ-D**, or evidence insufficient to establish the claimed behaviour.

## 4. Compound Rule

Where an E3-Q principle is compound, the evidence must support the compound at the level being counted.

A source supporting only one component may:
- support a parent cluster;
- receive functional C;
- or justify a narrower reformulation in the comparison note.

It must not silently count as A/B for the whole compound.

## 5. African Evidence Rule

“African Traditional” is a comparison family, not a single source.

Every secure row must name the actual evidence scope, for example:
- Akan;
- Ubuntu/Hunhu;
- Yoruba;
- Shona;
- another identified community/tradition;
- or a named scholarly synthesis whose scope is explicitly recorded.

## 6. Final Tier Calculation

Only after the seven comparison rows for a Q principle are audited should the project calculate cross-traditional prevalence.

Including the Qur'anic anchor, the final eight-family tiers remain:

- **Universal:** 8/8 secure functional presence
- **Near-universal:** 7/8
- **Common:** 5–6/8
- **Limited:** fewer than 5/8

A separate column should preserve provisional/corollary support so that uncertain evidence is not erased merely because it does not enter the secure count.

## 7. No Circular Repair

The final tier must be generated from the evidence rows.

The desired tier must never determine how a weak row is graded.

> **Evidence produces the prevalence classification; prevalence classification does not produce the evidence.**

> **End of Comparative Evidence Register Schema**
