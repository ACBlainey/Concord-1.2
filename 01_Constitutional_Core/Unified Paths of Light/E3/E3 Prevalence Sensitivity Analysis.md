# Sacred Codes and Civilizational Longevity — E3
## Prevalence Sensitivity Analysis

---

## 1. Purpose

The secure matrix intentionally treats **P — Provisional** evidence as non-counting.

This creates a lower-bound estimate. A sensitivity analysis asks what changes if provenance repair converts P rows into secure evidence without changing the underlying functional judgement.

## 2. Two Different Uncertainties

The matrix contains two fundamentally different reasons for a non-S cell:

### Documentary uncertainty
The functional match appears strong, but exact provenance is not yet sufficient.

Typical code: **P**.

### Substantive uncertainty
The comparison tradition supports only a parent, component or corollary rather than the frozen E3-Q principle itself.

Typical code: **C** or **U**.

These must not be conflated.

## 3. Expected Direction of Repair

Exact-source remediation should disproportionately improve:
- Sikh rows presently supported by concept-level evidence;
- African rows presently supported by scoped but insufficiently normalised scholarship;
- exact passage references for otherwise strong matches.

It should **not** automatically improve:
- procedural-child rows supported only by broad parent ethics;
- modern systems abstractions;
- principles where traditions genuinely differ.
