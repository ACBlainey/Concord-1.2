## Control rule

A candidate is promoted only when the final evidence record contains:
1. identifiable primary or authoritative Sikh source;
2. exact passage/location (normally Ang for SGGS);
3. a functional note showing that the source supports the **frozen principle**, not merely its parent;
4. SQ-A/B;
5. functional A/B.

Until all five conditions are met, the matrix remains unchanged.

The 7/8 repair pass established several upgrades using already identified exact passages. The present six candidates were identified primarily because their functional match appears strong, but the working repair notes do not yet contain sufficiently normalised exact locations for all six.

Creating this gate prevents a plausible memory of a source from becoming a quantitative result.
