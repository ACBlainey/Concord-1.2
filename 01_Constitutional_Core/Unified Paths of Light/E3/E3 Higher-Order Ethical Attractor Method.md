# Sacred Codes and Civilizational Longevity — E3
## Higher-Order Ethical Attractor Method

The 89 frozen E3-Q principles are deliberately granular. The prevalence audit therefore measures exact propositions, not necessarily the higher-order ethical attractors from which several propositions may descend.

This stage asks a different question:

> When the frozen principles are grouped without altering them, what higher-order ethical families recur across the catalogue?

This is an interpretive compression layer, not a new normalisation pass.

## Rules

1. The 89 Q identities remain frozen.
2. A Q principle may map to more than one attractor where function genuinely overlaps.
3. Parent-attractor prevalence must not be calculated by simply taking the highest child score.
4. Evidence for several differently worded children may jointly establish a parent ethic, but this must be explicitly audited.
5. No attractor is declared universal merely because one tradition contains a broad neighbouring value.
6. Concord Ethical Kernel categories may be compared only after E3-derived attractors are independently identified.

## Key distinction

The exact-proposition matrix asks:

> Does this tradition securely contain this particular behavioural rule?

The attractor analysis asks:

> Does this tradition securely instantiate the higher-order ethical function through one or more sufficiently direct rules?

That distinction is essential for interpreting Non-Harm.
