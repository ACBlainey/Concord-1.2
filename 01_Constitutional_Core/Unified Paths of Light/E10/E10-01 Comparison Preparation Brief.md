# E10-01 — Jainism Comparison Preparation Brief

**Status:** **READY FOR SOURCE RESOLUTION AND CORPUS FREEZE**

## Rationale

Jainism is useful for two reasons:
1. it restores a tradition present in the earlier E1 comparative work but absent from the current V1.2 sequence;
2. its independently derived ethical structure provides another out-of-sample test of the Unified Paths convergence finding.

## Required Preparation

Before extraction:
- identify and document an appropriate bounded Jain primary corpus;
- distinguish textual/source authority where traditions differ;
- select reliable editions/translations and stable locators;
- freeze inclusion/exclusion rules;
- preserve translation-sensitive Jain terminology;
- register the comparison prediction without using it to guide extraction.

## Method

**Source resolution → Corpus freeze → Independent extraction → Provenance audit → Internal normalisation/compression → Minimum-stability test → Jain kernel freeze → U1–U8 comparison**

Do not choose sources because they appear likely to reproduce the existing kernel.

## Current State

The experiment is prepared sufficiently to resume directly with source review and corpus-boundary work when time is available.
