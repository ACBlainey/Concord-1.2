# Unified Paths of Light — E8
## E8-11 — Opening Bani Extraction A: So Dar and So Purakh

## Coverage
Canonical opening bani following Japji, beginning ang 8. Guru Nanak and Guru Ram Das material conventionally grouped in the daily opening sequence. Extraction remains passage-led rather than keyword-led.

| ID | Source | Class / scope | Minimally normalised proposition |
|---|---|---|---|
| SO001 | So Dar opening, ang 8 | D/S | Human description is situated among many voices and forms and should not be mistaken for exhaustive representation. |
| SO002 | So Dar | D/G | Difference of role, voice and mode of participation can coexist within a larger order without requiring sameness. |
| SO003 | So Dar | V/S | Recognition of dependence counters inflated self-sufficiency and possessive self-attribution. |
| SO004 | So Purakh | V/S | Ego-centred self-assertion is treated as an obstacle to sound orientation and relationship. |
| SO005 | So Purakh | C/G | A common source and shared dependence are repeatedly asserted; no modern political equality doctrine is inferred solely from this theology. |
| SO006 | So Purakh | V/G | Devotional orientation is associated with release from fear and hostility; behavioural generalisation remains provisional. |
| SO007 | So Purakh | C/S | Association with ethically/spiritually oriented company is presented as shaping conduct and understanding. |
| SO008 | So Purakh | D/S | External status does not guarantee inner alignment or understanding. |
| SO009 | So Purakh | V/G | Humility is positively contrasted with self-magnification. |
| SO010 | So Purakh | C/S | Transformation is represented as relational and practised, not merely asserted verbally. |

## Controls
Theological unity is not converted automatically into civic egalitarianism. Liberation language is not coded as civil freedom unless a separable agency function is present.

## Marginal themes
Plural participation; humility; common dependence; social formation; anti-status orientation.
