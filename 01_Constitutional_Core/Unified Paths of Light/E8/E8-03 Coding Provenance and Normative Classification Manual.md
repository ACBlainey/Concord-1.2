# Unified Paths of Light — E8
## E8-03 — Coding, Provenance and Normative Classification Manual

## Ethical Source Unit
An **ESU** is the smallest contextually sufficient shabad, pauri, salok, stanza-family or connected passage from which a distinct behavioural or institutional proposition can responsibly be extracted.

Individual translated lines should not be detached where surrounding devotional/metaphorical context materially changes their function.

## Normative classes
- **P — Prescriptive:** directs or prohibits conduct.
- **V — Virtue/character:** identifies a cultivated disposition with behavioural consequence.
- **C — Consequential/causal:** links conduct/state to effects.
- **D — Deliberative:** supplies a method of judgement or discrimination.
- **N — Narrative/exemplary:** normative force depends on evaluated example.
- **X — Context-bound/non-general:** ethically relevant but not responsibly generalisable.

## Scope tags
- **G** general interpersonal
- **S** self-cultivation
- **F** family/close relation
- **C** collective/community
- **R** ruler/power/institutional
- **M** material/resource/economic
- **E** education/development
- **K** conflict/protection

## Required provenance fields
Each occurrence record should contain:
1. occurrence ID;
2. canonical ang/page;
3. composition/rāga where applicable;
4. attributed contributor;
5. source form;
6. normative class;
7. scope;
8. minimally normalised behavioural proposition;
9. contextual/theological limitation;
10. translation/concept note where material;
11. provenance confidence;
12. provisional **E8-internal** cluster only where useful.

## Translation-sensitive vocabulary
Do not force a single modern English equivalent onto terms including:
- hukam;
- nām;
- haumai;
- sevā;
- sangat / sādh sangat;
- gurmukh / manmukh;
- sach / sat;
- santokh;
- dayā;
- dharam;
- nimratā;
- vand / sharing vocabulary;
- sarbat where encountered;
- nirvair;
- kirat-related formulations where textually supported.

## Theology-to-ethics rule
A theological claim qualifies only if a separable functional proposition is warranted.

Examples of prohibited shortcuts:
- divine unity → automatically “political equality”;
- hukam → automatically “obedience to authority”;
- nām remembrance → automatically a generic truth principle;
- liberation language → automatically civilisational ethics.

## Contributor rule
The canon includes Guru and non-Guru compositions. Canonical inclusion permits extraction, but contributor identity is retained so recurrence across contributors is not falsely treated as independent cultural convergence.

## Repetition rule
Repeated liturgical or poetic formulations are evidence of emphasis, not principle multiplicity.

## Anti-contamination
During derivation:
- do not code passages against X1–X7;
- do not search the scripture for expected X vocabulary;
- do not use previous E-series labels as provisional clusters;
- do not infer a target number of roots.
