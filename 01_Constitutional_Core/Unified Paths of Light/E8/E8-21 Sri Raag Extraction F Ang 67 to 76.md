# Unified Paths of Light — E8
## E8-21 — Sri Raag Extraction F: Ang 67–76

## Coverage
Sequential Sri Raag coverage from ang 67 through ang 76. This block includes Guru Amar Das material and preserves explicit social-status examples without converting theology into a modern political doctrine.

|---|---|---|---|

## Source-control note
Ang 67 explicitly contrasts action without understanding with guided practice, while ang 68 uses Brahmin, Namdev and Kabir examples to decouple substantive standing from inherited/social classification. These are unusually useful status/function records.
