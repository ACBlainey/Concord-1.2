# Unified Paths of Light — E8
## E8-169 — Kabir Saloks Extraction C: Ang 1374–1377 and Closure

## Boundary control
Independent structural indices place Kabir's saloks at ang 1364–1377 and Sheikh Farid's saloks beginning on ang 1377. Direct page inspection confirms that ang 1377 contains the terminal Kabir saloks followed later on the same ang by the heading for Sheikh Farid.

## Direct-source anchors
Ang 1374 explicitly compares the body to gathered dust that shortly returns to dust. The same page marks speech after careful consideration. Ang 1377 explicitly associates a good giver with compassion and living for beneficent action.
