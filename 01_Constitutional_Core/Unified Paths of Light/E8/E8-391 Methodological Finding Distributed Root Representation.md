# Unified Paths of Light — E8
## E8-391 — Methodological Finding: Distributed Root Representation

## Observation
E8 exposed a distinction not fully visible in a simple one-root-to-one-root comparison.

A target function may be substantively present across several independently derived parents without appearing as one matching parent.

X1 and X6 illustrate this problem.

## Distributed representation
A function is **distributed** where:
- multiple frozen parents jointly cover important parts of the target;
- no individual parent carries the complete target function;
- merging those parents merely to create a match would damage the independently derived architecture.

Distributed representation must therefore not automatically be scored as full recovery.

## Consequence for holdout scoring
The R/A/Ø system correctly allows:
- **R** where functional equivalence is sufficiently complete;
- **A** where representation is substantial but distributed or incomplete;
- **Ø** where substantive representation is absent.

This protects the experiment against post-hoc compression toward the target.

## Broader methodological implication
Cross-cultural ethical comparison should distinguish:
1. presence of a function;
2. location of that function in an architecture;
3. partition boundaries;
4. level of abstraction;
5. whether the function is a root, operator, condition, constraint or derived rule.

Two traditions can therefore occupy similar functional space without possessing isomorphic ethical taxonomies.
