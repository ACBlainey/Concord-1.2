# Ten Commandments Comparative Project
## P7 — Upward Trace: From Command to Root

This pass starts with each Decalogue command and asks what minimum secular ethical structure is required to explain its behavioural function. Theology is retained as residual where secular compression cannot preserve it.

| Command | L2 domain function | L1 attractor | plausible L0 root(s) | residual |
|---|---|---|---|---|
| exclusive allegiance | covenantal loyalty / ultimate allegiance | Trust/Responsibility only partially | no secure secular root equivalent | divine exclusivity |
| no idols | fidelity of representation/allegiance | Epistemic Integrity / Anti-Domination only partially | Truth, Anti-Capture by analogy | worship/idolatry itself |
| divine name | truthful use of sacred identity/authority | Epistemic Integrity + Trust | Truth | sacred status of the name |
| Sabbath | bounded labour/rest; restraint; protected participation | Care + Self-Regulation + Stewardship | Non-Harm + Stewardship; autonomy/boundary implications | worship/covenant/time sanctification |
| honour parents | intergenerational obligation and relational continuity | Care + Trust + Social Cohesion | Non-Harm plus responsibility; not fully reducible with confidence | specifically filial duty |
| no murder | protection of life | Non-Harm/Protection | Non-Harm | none for secular behavioural core |
| no adultery | intimate boundary + fidelity | Autonomy/Consent + Trust | Autonomy + Non-Harm; Truth/commitment implications | historically specific marriage assumptions |
| no theft | possession/consent boundary | Agency + Trust + Stewardship | Autonomy + Stewardship + Non-Harm | property regime not specified by roots |
| no false witness | evidential integrity in judgement | Epistemic Integrity + Justice | Truth + Non-Harm | judicial/testimonial domain |
| no coveting | regulate acquisitive motivation before violation | Self-Regulation + Stewardship + Anti-Domination | Non-Harm + Autonomy + Stewardship | command reaches intention/desire itself |

## Finding

The upward trace repeatedly requires **fewer roots than commands**.

Several different commands collapse toward the same roots:
- murder → Non-Harm;
- false witness → Truth + Non-Harm;
- theft → Autonomy + Stewardship;
- adultery → Autonomy + Non-Harm plus trust;
- coveting → restraint around Non-Harm/Autonomy/Stewardship.

This is what would be expected if the Decalogue operates downstream of a more compressed kernel.

However, not everything compresses cleanly. Filial duty introduces a positive relational obligation that is not obviously derivable from negative restraint alone, while the theological commands retain irreducible covenantal content.

These residuals are important tests against over-compression.

> **End of P7**
