# Archived Graduated Sketches

**Status:** PROVENANCE ARCHIVE — NOT LIVE SKETCH QUEUE

This folder contains originating Sketch Ideas that have crossed the sketch threshold and progressed into dedicated Development Notes or substantive development programmes.

They are retained because the original sketch records:
- the originating question;
- early assumptions;
- initial scope;
- provenance of later development;
- and the path by which an idea graduated.

## Governing Rule

> **Once a sketch has clearly graduated into a Development Note or substantive development programme, move the originating sketch out of the live Sketch Ideas area and into this archive.**

Archiving does **not** mean the idea is complete, canonical or correct.

It means:

> **This is no longer a live incubation-stage sketch. Follow the linked Development Note/programme for current work.**

The archive therefore prevents completed promotions from being mistaken for undeveloped backlog.

## Archive Criteria

Move a sketch here when:
1. a dedicated Development Note or development programme now owns the substantive work;
2. the sketch is retained mainly for provenance;
3. continuing work should occur outside the live sketch queue.

Do not archive merely because a sketch is:
- ready for development;
- a bounded experiment candidate;
- partially answered;
- dependency-blocked;
- a canonical-system test case;
- or temporarily inactive.

Those may remain live sketches until substantive ownership has actually transferred.

## Provenance Rule

Do not delete archived originating sketches merely because later work supersedes portions of them.

Where later development materially changes the concept, preserve both:
- originating sketch;
- later Development Note / canonical architecture.

This archive is historical provenance, not the current authority for the developed system.
