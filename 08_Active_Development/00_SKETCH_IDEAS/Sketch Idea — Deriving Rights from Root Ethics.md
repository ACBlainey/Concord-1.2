# Sketch Idea — Deriving Rights from Root Ethics

**Status:** SKETCH / UNTESTED / NON-CANONICAL
**Origin:** Unified Paths / constitutional-topology backlog.

## Problem
What transforms a root ethical constraint into a civil right, and at what abstraction level do rights operate relative to root ethics?

## Sketch
Test whether rights can be represented as protected civil claims or standing generated where ethical roots constrain how participants may be treated.

Candidate conceptual chain:

**Root Ethic → Protected Interest/Agency Condition → Civil Standing/Claim → Right → Duties/Constraints on Others and Institutions → Remedy/Review**

This is a hypothesis, not a derivation yet.

## Questions
- Can one right derive from several roots?
- Can one root generate several rights?
- Which rights are context-dependent versus invariant?
- What makes a right immutable, if anything?
- How do rights differ from permissions, protections, entitlements and duties?
- Can a proposed core set be derived from Blainey's Laws without simply restating existing constitutional rights?

## Possible Tests
Blind derivation from the kernel followed by comparison with canonical rights architecture and external rights frameworks.
