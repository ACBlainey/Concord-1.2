## Canonical Test-Case Routing

### TC-01 — Galaxy Quest Dilemma → L3-15

Do not independently develop another memory architecture.

Use the defensive-memory core as a Cold Memory / Functional Forgetting test:

> Can a civilisation remove hostile/adversarial knowledge from ordinary active context while preserving enough recoverable provenance to recognise and respond to recurrence?

Failure cases:
- knowledge becomes irrecoverable;
- harmful knowledge remains routinely active without need;
- retrieval occurs without revalidation;
- obsolete records regain current-truth status;
- defensive memory becomes a pretext for pervasive suspicion or surveillance.

### TC-02 — Peaceful Shielding → Identity/Fork/Distance Architecture

Before creating a mechanism, test against L2-11 Identity/Membership/Boundary Continuity, L3-05 Fork/Succession/Recombination, L3-14 Peaceful Non-Participation and Distance, L3-06 Functional Recognition, fiduciary/capacity support, Safe Spaces and wrapper architecture.

## Back-Propagation Rule

When substantial canonical development, experimental results or new evidence appears, review related sketches for status change.

Possible transitions:

OPEN → READY FOR DN
OPEN → EXPERIMENT
OPEN → TEST CASE
OPEN → PARTIALLY SUPPLIED
OPEN → OVERTAKEN
OPEN → CLOSED/ANSWERED
HOLD → READY
READY → HOLD

Back-propagation works in both directions.

## Relationship to CDT

The sketch portfolio must not become another Civilisation Clock.

CDT/Clock selects development using civil state, dependency, consequence and readiness.

The sketch portfolio preserves and matures candidate ideas before they become formal developmental objects.

Useful bidirectional interface:

**Sketch Portfolio → Mature Candidate → Active Development**

and

**Civil State → Development Need → Search Existing Sketches/Notes/Systems → Reuse or Develop**

This creates discovery without giving the sketch folder authority over civil priorities.
