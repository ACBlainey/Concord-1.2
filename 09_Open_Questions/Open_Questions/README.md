# Open Questions

This folder contains the current unresolved questions of Concord V1.2 and supporting current open-question registers.

Historical audits and temporal snapshots should not be treated as current open-question state merely because they remain preserved elsewhere in the repository or in frozen Concord V1.1.

Questions that are sufficiently resolved, retired, rejected as premises, or moved outside required Concordian civil scope should be transferred to the sibling `Closed_Questions` area with enough information to explain their present disposition.

The purpose of this folder is to make the Concord's current uncertainty visible and usable for active research.
